# 조사 체크리스트

## 원칙
- 공개된 정보만 기록하고 모든 항목에 출처 URL과 수집일을 남긴다.
- 확인 안 된 항목은 비우거나 "미확인"으로 표시한다. 추측으로 채우지 않는다.
- 강사 정보는 본인·학원이 직접 공개한 것(홈페이지, 공식 SNS, 네이버 플레이스)만 쓴다.
- 입력 순서: academies → people → career_items

## 학원 1곳당 확인 항목
- [ ] 학원알리미/공공데이터 사이트에서 등록 여부, 주소, 교습과목, 교습비 확인
- [ ] 네이버 플레이스에서 위치, 영업시간, 전화, 홈페이지·인스타 링크 확인
- [ ] 초·중등 대상 수업이 실제로 있는지 확인 (성인·입시 전문이면 제외)
- [ ] 분야 분류: 보컬 / 댄스 / 발레 / 탭댄스 / 아크로바틱 / 체조 / 연기 / 뮤지컬 종합 (발레·현대무용은 `발레`, 방송·K팝·힙합·재즈 등은 `댄스`, 키즈보컬은 `보컬`)
- [ ] 대상 학년, 수강료(공시 금액과 홈페이지 안내가 다르면 둘 다 메모), 요일·시간, 정원·수업 방식
- [ ] 발표회·공연·오디션 이력, 개원 연도
- [ ] 원장·강사: 공개 이름/직함, 학원 운영 경력, 뮤지컬 출연·스태프 경력, 강의 경력, 학력, 수상
- [ ] 뮤지컬 출연 경력은 KOPIS 등에서 작품·연도 교차 확인 후 verified=TRUE

## 직접 문의가 필요한 항목
- [ ] 정확한 수강료와 교재·공연비 등 추가 비용
- [ ] 체험 수업 가능 여부
- [ ] 온라인에 없는 강사 경력 (공개 동의를 받은 경우만 기록)
- [ ] 정보 게재에 대한 학원 측 의견

## 입력 후 점검
- [ ] 모든 경력 항목에 출처가 있는가
- [ ] 중복 학원이 없는가 (이름·주소 기준)
- [ ] 지도에서 좌표가 실제 위치와 맞는가
- [ ] last_verified_at이 6개월을 넘으면 재확인

> 시트에서 내보낸 CSV는 `npm run import -- <폴더>`로 먼저 검사하고, 오류 0건일 때 `--write`로 반영합니다. 검사기가 위 점검 중 기계로 확인 가능한 항목(출처 URL 누락, 이름·주소 중복, 서울 범위 밖 좌표, 6개월 경과, verified 오용, 없는 학원·인물 id 참조)을 자동으로 잡아 줍니다. 좌표가 *실제 위치와 맞는지*는 지도에서 직접 확인해야 합니다.

## CSV 입력 메모 (앱에서 추가로 쓰는 규칙)
- 분야 값: `보컬`, `댄스`, `발레`, `탭댄스`, `아크로바틱`, `체조`, `연기`, `뮤지컬종합` (띄어쓰기 없이)
- 동네는 주소의 법정동(마곡동·화곡동·내발산동·외발산동·가양동)으로 자동 분류되므로 주소에 동 이름을 꼭 넣기
- 배열 칸(categories, target_grades, subjects, schedule_slots)은 세미콜론 `;`으로 구분
- 값에 쉼표가 들어가면 칸 전체를 큰따옴표로 감싸기 (엑셀·구글시트 내보내기는 자동 처리)
- 날짜는 `YYYY-MM-DD`, verified는 `TRUE`/`FALSE`
- 필터용 선택 컬럼(academies.csv 끝 3개, 비워도 됨):
  - `tuition_monthly_min`, `tuition_monthly_max`: tuition_note에서 **확인된** 월 금액(원)만 숫자로. 문의 필요면 비움
  - `schedule_slots`: `화 16:00-18:00;목 16:00-18:00` 형식. 확인 안 됐으면 비움
