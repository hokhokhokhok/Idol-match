# 감정평가사 1차 모의고사 — 민법 · 경제학원론 · 부동산학원론 · 감정평가관계법규 (오프라인 PWA)

아이패드에서 매일 **민법**, **경제학원론**, **부동산학원론**, **감정평가관계법규(감관법)** 모의고사를 실제 시험지 조판(바탕/명조, ①~⑤, <보 기> 박스, 표 지문)으로 풀고
해설·근거 조문·오답노트·약점 통계를 보는 앱. 홈 상단 탭으로 과목을 고른다. 계정·서버 없이 기기(IndexedDB)에만 저장한다.

> 폴더 이름(`civil-exam/`)·배포 주소·IndexedDB 이름은 민법 앱 때와 같다 — 기존 기록이 그대로 이어진다.

> 같은 저장소 루트의 '아이돌 매칭 맵'과는 별개 앱이다. 이 폴더(`civil-exam/`)만으로 빌드된다.

## 실행

```bash
cd civil-exam
npm install
npm run dev        # 개발 서버
npm test           # 단위 테스트(vitest)
npm run validate   # 문항 세트 검증 (오류가 있으면 실패)
npm run build      # 문항 검증 + 타입검사 + 프로덕션 빌드(dist/, 서비스워커 포함)
npm run test:e2e   # 빌드 결과를 아이패드 5가지 화면 크기로 자동 점검 + 감관법 흐름 (BROWSER=webkit 가능, SHOTS=1 스크린샷, CHROMIUM_PATH=설치된 크로미움)
npm run preview    # 빌드 결과 확인 (아이패드에서는 같은 Wi-Fi로 접속: npm run preview -- --host)
```

Node 22.18 이상 필요(검증 스크립트를 TypeScript 그대로 실행). 실제 아이패드 확인은 [docs/ipad-checklist.md](docs/ipad-checklist.md) — HTTPS 주소로 올려야 오프라인이 동작한다.

**배포:** `main`에 병합하면 GitHub Pages가 https://hokhokhokhok.github.io/Idol-match/civil-exam/ 로 배포한다(`.github/workflows/pages.yml`). 다른 하위 경로에 배포할 때는 `BASE=/저장소명/경로/ npm run build`.

## 시험 모드 사용법

- 홈 → **실전 시작**. 제한시간은 `config/exam.json`의 40분을 40문항 기준으로 두고 세트 문항 수에 비례해 정한다(시드 5문항 = 5분).
- 타이머를 탭하면 숨김/표시. 남은 시간이 5분(짧은 세트는 제한시간의 10%) 이하면 빨간색. 0이 되면 자동 제출.
- 문제 이동: 시험지를 **좌우로 스와이프**, 아래 이전/다음 버튼, 답안지 번호 탭, 키보드 ←/→.
- 보기를 탭하면 마킹, 같은 보기를 다시 탭하면 해제(키보드 1~5).
- **답안지**: 가로 화면은 오른쪽에 고정, 세로 화면은 상단 '답안지' 버튼으로 연다. 마킹한 칸은 칠해지고 고른 번호가 보이며 별표 문항엔 ★.
- **제출** → 미응답·별표 문항 목록 확인(번호를 탭하면 그 문항으로 이동) → 채점 결과(점수, 단원별 정답률, 문항별 O/X).
- 결과 화면에서 **전체 해설** / **틀린 문항 해설**, 또는 문항별 O/X 칸을 탭해 해설로 간다. 해설은 핵심 요약 → 보기별 해설(정답·내 답 표시) → 근거 조문 → 판례(`verified: false`면 '판례 확인 필요').
- 해설 화면에서도 스와이프·←/→로 이동, 상단 **틀린 문항만** 토글, 세로 화면은 '문항 목록'으로 채점표를 연다.
- 제출 기록은 기기의 IndexedDB에 저장되고 홈 **최근 기록**에서 다시 열 수 있다. 문항별 풀이시간도 함께 저장된다(4단계 통계용).
- 풀던 내용은 기기에 바로 저장된다. 앱을 닫거나 '나가기' 후에도 홈에서 **이어 풀기**. 시간은 실제 시각 기준으로 계속 흐른다.

## 경제학원론

- 시험 포맷: 40문항·2.5점, 기본 40분(1교시 120분을 세 과목이 나눔), 과락 40점. 계산기 허용 여부는 `config/econ/exam.json`의 `calculator`에 Q-Net 공고 확인 후 기록.
- 시험지: 수식(KaTeX), 그래프(SVG), 표(보수행렬·비교우위 등), 왼쪽 위 '영역 · 단원' 배지.
- 해설: 계산형은 **풀이 단계**와 '계산 검증 완료 · 내용 검수 필요' 배지(계산은 코드로 확인됨), 개념형 미검수는 '교재 대조 필요'.
- 통계: 단원별 + 미시·거시 + 계산형·개념형 정답률, 약점 단원 Top3, 홈 '오늘의 추천 약점 복습'.
- 홈 **계산 문제만 풀기**, **곡선 이동 퀴즈**(상황을 읽고 곡선이 왼쪽/오른쪽/이동 없음 중 고르면 이동한 곡선을 점선으로 보여 줌).
- 설정 → **시험 화면 계산기**: 켜면 경제학원론 시험 화면 위쪽에 계산기 버튼.
- 문항 만들기·계산 검증 규칙: [docs/econ-content-workflow.md](docs/econ-content-workflow.md)

## 감정평가관계법규(감관법)

- 홈 상단 **민법 / 감정평가관계법규** 탭. 고른 탭은 기억한다. 풀던 시험(이어 풀기)은 과목과 관계없이 하나.
- 시험 포맷: 40문항·문항당 2.5점, 기본 **40분**(2교시 80분을 회계학과 나눔 — 설정에서 변경), 결과에 과락(40점 미만) 표시. `config/law/exam.json`.
- 시험지: 왼쪽 위 **법률명 배지**(국토계획법 등), 표 지문(건폐율·용적률 등), 긴 법령명 줄바꿈 처리.
- 해설: **기준 법령일 배지**, 수치·기간 문항은 '개정 확인 필요', 미검수는 '조문 확인 필요'. **근거 조문**은 법/시행령/시행규칙 구분, 누르면 조문 원문 팝업(`law-texts/`에 넣은 경우, 없으면 국가법령정보센터 링크).
- 통계: 9개 법률별 누적 정답률 + **최근 5회 추세**(그 법률 문항이 있던 실전 회차의 정답률), 약점 법률 Top3, 문항 유형(정의·숫자·기간·절차·순서·예외·단서·사례)별·형식별 정답률.
- 홈 **오늘의 추천 약점 복습**: 실전 정답률이 가장 낮은 법률에서 10문항(오늘 복습할 오답 → 틀린 적 있는 문항 → 안 푼 문항 순), 고르는 즉시 해설. 틀리면 오답노트로.
- 오답노트: 법률·문항 유형 필터.
- **숫자·기간 암기 카드**(홈 타일): 해설 속 수치를 빈칸으로 만든 카드. 오답노트 문항의 카드부터, 알면 1·3·7·14·30일 뒤, 모르면 다음 날.
- 설정 → **조문으로 찾기**: 법령이 개정되면 조문(예: `국토계획법 시행령 제84조`)으로 영향받는 문항을 찾는다. 약칭·공백 무시.
- 맞춤 모의고사: 감관법 문항 풀에서 `config/law/blueprint.json` 법률별 배분(±1) + 약점 법률 +2.

## 오늘의 세트 · 맞춤 모의고사

- **오늘의 모의고사(매일 새로 5세트)**: 과목마다 홈에서 그날의 40문항 세트 5개를 바로 시작한다. 시드 세트를 뺀 전체 문항 풀에서 단원(법률) 배분대로 고르고, 안 푼 문항 → 틀린 문항 → 맞힌 문항 순으로, 같은 날 5세트끼리는 문항이 최대한 겹치지 않게(160문항이면 각 문항 1~2회) 구성한다. 그날 처음 열 때 만들어 기기에 저장하므로 하루 동안은 구성이 같고, 다음 날 새로 바뀐다(전날 나온 문항은 뒤로 미룸). 제출하면 세트 칸에 최고 점수가 표시되고 기록에는 "오늘의 모의고사 n · 월.일"로 남는다. (`src/lib/plan.ts` `buildDailySets`, `src/lib/daily.ts`)

- **오늘의 세트**: 홈 맨 위. 아직 제출하지 않은 세트 중 첫 번째(id 순), 모두 풀었으면 가장 오래전에 푼 세트를 다시 권한다. 시드 세트는 제외.
- **맞춤 모의고사**: 모든 세트(시드 제외)의 문항에서 40문항을 새로 구성한다. 기획안 10절대로 `config/blueprint.json` 단원 배분에 단원별 ±2 무작위 변동, 설정의 **약점 단원 가중치**가 켜져 있으면 실전 정답률이 가장 낮은 단원에 +2. 단원 안에서는 안 푼 문항 → 틀린 적 있는 문항 → 맞힌 문항 순으로 고르고, 시험지처럼 총칙 → 물권 → 계약 순으로 배열한다. 문항 id는 원래 세트의 것을 쓰므로 오답노트·통계와 이어진다.

## 오답노트 · 통계

- 실전에서 틀리거나 비운 문항은 자동으로 **오답노트**에 들어가고 **다음 날** 복습 대상이 된다.
- 복습에서 맞히면 3일 뒤 → 다시 맞히면 7일 뒤 → 또 맞히면 **졸업**. 중간에 틀리면 다시 1일 뒤부터. 실전에서 또 틀려도 1일 뒤로 돌아간다.
- 복습일 전에 '풀기'로 미리 풀어 맞혀도 일정은 그대로(틀리면 1일 뒤로 리셋).
- 복습은 한 문항씩: 보기를 고르면 바로 채점·해설.
- 각 문항에 **별표**와 **메모**. 필터: 오늘 복습 / 진행 중 / 별표 / 졸업.
- **통계**(실전 제출 기록 기준): 연속 학습일, 평균 점수, 문항당 풀이시간, 오답노트 현황·복습 정답률, 점수 추이, 단원별·유형별 누적 정답률(+평균 풀이시간), 회차별 기록.
- 홈: 연속 학습일(실전 제출 또는 복습한 날), 오늘 복습 문항 수, 약점 단원 Top3(단원별 3문항 이상 풀었을 때).

## 설정 · 백업

- 홈 우측 상단 **설정**.
- **시험지 글자 크기**: 작게 15 / 보통 17 / 크게 19px.
- **시험시간**: 40문항 기준 10~150분(5분 단위, 기본은 `config/exam.json`). 다른 문항 수 세트는 비례. 진행 중인 시험에는 적용 안 됨.
- **해설 즉시 보기(연습 모드)**: 켜면 세트를 연습 모드로 시작 — 시간 제한 없이 경과 시간만 표시, 보기를 고르면 바로 정답/오답과 보기별 해설(답 변경 불가). 끝나면 제출해 결과 저장. 연습 결과도 오답노트·연속 학습일에는 반영되지만 **통계(점수·정답률)·약점 단원은 실전만** 집계.
- **백업 파일 만들기**: 두 과목의 모든 기록(시험 기록, 문항 결과, 오답노트·메모, 복습 기록, 암기 카드, 진행 중 시험, 설정)을 `civil-exam-backup-YYYYMMDD-HHMM.json`으로. 아이패드에서는 공유 시트 → '파일에 저장'.
- **백업에서 복원**: 파일을 고르면 내용 요약과 함께 확인 → 현재 기기 기록을 **전부 백업 내용으로 교체**(한 트랜잭션이라 실패하면 기존 기록 유지). 다른 앱 파일·손상된 파일은 거부.
- 앱 시작 시 저장공간 보호(`navigator.storage.persist`)를 요청한다. 설정 화면에서 상태 확인.

## 문항 검증 (`npm run validate`)

`src/data/sets/*.json` 전체(또는 `npm run validate -- 파일.json`)를 검사한다. 빌드 때 자동 실행되어 **오류가 있으면 빌드가 멈춘다**.
과목(`subject`)마다 규칙이 다르다 — 아래 표는 민법, 감관법 추가 규칙은 [docs/law-content-workflow.md](docs/law-content-workflow.md#②-자동-검증) (legalBasis·lawAsOf 누락은 오류, 복수 정답 의심·volatile 누락·법률별 배분 ±1·분량(`config/law/length.json`)은 경고).

| 수준 | 내용 |
|---|---|
| ✗ 오류 (실패) | 스키마: id·setId(=파일 이름)·number 1~40·unit·type·difficulty·`source`("original" 창작 / "past" 기출 — 기출이면 `pastExam` 필수)·reviewed, 보기 정확히 5개(번호 기호 없이, 중복 없이), 정답 1~5, 해설 summary·perChoice 5개·statutes·cases(gist, verified), 마크업(`**`, `<u>` 짝, 다른 태그 금지), 조합형·개수형 박스 ㄱ~ㄹ 순서와 조합 보기의 기호, 번호·id 중복(세트 간 포함), JSON 문법 |
| △ 경고 | 보기별 해설에서 '정답'으로 설명한 보기와 `answer` 불일치 / 기획안 7절 분량(공백 포함, 마크업·"(다툼이 있는 경우 판례에 따름)" 제외): 발문·사실관계·보기·박스 항목·문항 전체 글자 수 / 유형별 발문 표현("모두 고른 것은", "몇 개", "판례", 갑·을·병) / id 형식 `세트-qNN` / 40문항 세트의 단원 배분(`config/blueprint.json` ±2)과 정답 번호 분포 |
| · 참고 | 미검수(`reviewed: false`), 판례 미확인(`verified: false`), 40문항이 아닌 세트 |

옵션: `--strict`(경고도 실패), `--quiet`(참고 숨김), `--json`(기계 판독용 출력).

## 시험지 조판

- 본문: KoPubWorld바탕(기기에 설치돼 있으면 사용) → **나눔명조(번들)** → Noto Serif KR
- UI·해설: **Pretendard(번들)** → Noto Sans KR
- 본문 15/17/19px(기본 17), 줄간격 1.75, 자간 -0.01em, `justify` + `keep-all`, 지면 #FFFEFA / 글자 #111
- 보기 왼쪽 여백의 작은 버튼을 탭하면 **밑줄 → X(제외) → 없음** 순으로 표시가 바뀐다 (Apple Pencil 탭으로도 동작)
- `reviewed: false` 문항은 우측 상단에 '미검수' 표시

## 문항 정책

기출·학원·공단 문항을 옮기지 않고 출제 경향만 반영한 창작 문항(`source: "original"`)을 쓴다.
판례는 `verified: false`로 시작해 대법원 종합법률정보에서 확인한 뒤 `true`로 바꾼다.
시드 5문항은 AI 작성분이므로 조문·판례·복수정답 여부를 직접 검수해야 한다.
