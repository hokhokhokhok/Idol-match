# 아이패드 Safari 테스트 체크리스트

`npm run test:e2e`가 데스크톱 브라우저로 화면 크기·흐름·오프라인·백업을 자동 점검한다.
이 문서는 **실제 아이패드에서만** 확인할 수 있는 것(홈 화면 앱, 사파리 렌더링, 터치·펜슬, 공유 시트, 백그라운드 전환)을 다룬다.

## 0. 준비 — 컴퓨터에서

```bash
cd civil-exam
npm ci
npm test              # 단위 테스트
npm run validate      # 문항 세트 검증 (오류 0이어야 함)
npm run build         # 검증 → 타입검사 → dist/ 생성 (검증 오류가 있으면 여기서 멈춤)
npm run test:e2e      # 아이패드 크기별 자동 점검 (Chromium)
BROWSER=webkit npm run test:e2e   # 선택: 사파리 엔진(WebKit)으로 한 번 더. 최초 1회 npx playwright install webkit
```

- [ ] 위 명령이 모두 통과했다

### HTTPS 주소로 올리기 (필수)

서비스워커(오프라인 동작)는 **HTTPS**에서만 켜진다. `npm run preview -- --host` 후 `http://192.168.x.x`로 접속하면
화면은 열리지만 **오프라인·홈 화면 앱 캐시가 동작하지 않으므로** 테스트로 인정하지 않는다. 다음 중 하나로 올린다.

가장 쉬운 방법은 GitHub Pages다. 루트 아이돌 앱의 서비스워커는 `/civil-exam/` 경로를 건드리지 않도록 수정해 두었으므로, 같은 기기에서 두 앱을 모두 써도 서로 간섭하지 않는다.

| 방법 | 절차 |
|---|---|
| Netlify Drop (가장 빠름) | app.netlify.com/drop 에 `dist/` 폴더를 끌어다 놓기 → https 주소 발급 |
| Vercel / Cloudflare Pages | 저장소 연결, 루트 `civil-exam`, 빌드 `npm run build`, 출력 `dist` |
| **GitHub Pages (설정 완료)** | 이 브랜치를 `main`에 병합하면 `.github/workflows/pages.yml`이 아이돌 앱과 함께 빌드해 **https://hokhokhokhok.github.io/Idol-match/civil-exam/** 에 배포한다 (테스트·문항 검증 실패 시 배포 중단) |

- [ ] 아이패드 사파리에서 https 주소가 열린다
- 테스트 기기 / iPadOS 버전: ____________ / 배포 주소: ____________

## 1. 설치 (홈 화면에 추가)

- [ ] 사파리 공유(□↑) → **홈 화면에 추가** → 이름이 "민법 모의고사"로 제안된다
- [ ] 홈 화면 아이콘이 남색 시험지 아이콘으로 보인다 (흰 사각형·스크린샷 아님)
- [ ] 아이콘으로 열면 사파리 주소창 없이 전체 화면으로 열린다
- [ ] 상단 상태 표시줄(시계·배터리)과 앱 상단 바가 겹치지 않는다 (세로·가로 모두)
- [ ] 설정 → 데이터 백업·복원의 "저장공간 보호"가 **켜짐**이다 (꺼짐이면 결과에 기록만 해 둔다)

## 2. 오프라인

- [ ] 홈 화면 앱을 한 번 연 뒤 완전히 종료(앱 전환기에서 위로 밀기)
- [ ] **비행기 모드**에서 다시 연다 → 홈이 정상으로 뜬다
- [ ] 비행기 모드 그대로: 실전 시작 → 40문항(시드는 5문항) 풀이 → 제출 → 해설까지 막힘 없다
- [ ] 비행기 모드에서도 시험지 글꼴이 명조체 그대로다 (고딕·기본 글꼴로 바뀌지 않음)

## 3. 시험지 조판 (글꼴 깨짐 없음)

각 글자 크기(설정: 작게 15 / 보통 17 / 크게 19)마다 한 번씩 본다.

- [ ] 본문·보기가 명조체, 해설·버튼이 고딕체다
- [ ] ①②③④⑤, ㄱ·ㄴ·ㄷ·ㄹ, 「」, ·, — 등 기호가 □(두부)로 깨지지 않는다
- [ ] `<보 기>` 박스: 얇은 검정 테두리, 제목 가운데, ㄱ~ㄹ 내어쓰기 정렬
- [ ] 보기 ①~⑤ 둘째 줄이 번호 뒤 글자에 맞춰 들어가 있다 (내어쓰기)
- [ ] 어절이 줄 끝에서 쪼개지지 않는다 (keep-all), 양쪽 정렬로 간격이 지나치게 벌어진 줄이 없다
- [ ] "옳지 <u>않은</u>" 밑줄이 보인다, 문항 번호·발문이 굵다
- [ ] 우측 상단 "미검수" 배지가 본문과 겹치지 않는다

## 4. 화면 방향 · 크기

- [ ] **세로**: 답안지가 숨겨져 있고, 상단 "답안지 n/40" 버튼으로 오른쪽에서 나온다. 바깥을 탭하면 닫힌다
- [ ] **가로**: 시험지 왼쪽, 답안지 오른쪽 고정
- [ ] 시험 중 기기를 돌려도 현재 문항·마킹이 유지되고 레이아웃이 바로 바뀐다
- [ ] Split View(1/3, 1/2)·Stage Manager 작은 창에서 가로 스크롤 없이 쓸 수 있다

## 5. 터치 · 애플 펜슬 · 키보드

- [ ] 보기를 탭하면 번호가 OMR처럼 검게 칠해지고, 같은 보기를 다시 탭하면 해제된다
- [ ] 빠르게 두 번 탭해도 화면이 확대되지 않는다
- [ ] 시험지를 **좌우로 밀면** 이전/다음 문항, **위아래로 밀면** 스크롤만 된다 (대각선으로 밀어도 오작동 없음)
- [ ] 보기 왼쪽 여백의 점(·)을 탭: 밑줄 → ✕(취소선) → 없음 순환. **애플 펜슬로 탭**해도 같다
- [ ] 펜슬로 보기를 탭해 마킹할 수 있다 (손가락과 동일)
- [ ] 버튼이 작아서 잘못 눌리는 곳이 없다 (설정 스위치, 답안지 번호, 제출 모달 번호 포함)
- [ ] (키보드 연결 시) ←/→ 문항 이동, 1~5 보기 선택

## 6. 타이머 · 앱 전환 · 이어 풀기

- [ ] 남은 시간이 1초씩 줄고, 탭하면 "시간 숨김" ↔ 표시
- [ ] 시험 중 홈 화면으로 나갔다가 2분 뒤 돌아오면 남은 시간이 **2분 줄어 있다**
- [ ] 화면을 잠갔다 풀어도 같다
- [ ] 시험 중 앱을 완전히 종료 → 다시 열면 홈에 "이어 풀기"가 있고 마킹·별표·밑줄이 남아 있다
- [ ] 설정에서 시험시간을 짧게(10분) 하고 5문항 세트로 시간 종료까지 기다리면 자동 제출되고 "시간이 종료되어…" 안내가 뜬다
- [ ] 남은 시간이 경고 시점 이하가 되면 빨간색으로 바뀐다

## 7. 제출 · 채점 · 해설

- [ ] 제출 → 미응답 n문항·별표 문항 목록, 번호를 탭하면 그 문항으로 이동
- [ ] 결과: 점수, 단원별 정답률 막대, 문항별 O/X → 칸을 탭하면 해설
- [ ] 해설: 정답 초록·내 오답 빨강, 보기별 해설, 근거 조문, "판례 확인 필요" 배지
- [ ] "틀린 문항만" 토글, 스와이프로 오답끼리 이동

## 7-1. 오늘의 세트 · 맞춤 모의고사

- [ ] 홈 맨 위 '오늘의 세트'가 아직 안 푼 세트(2026-001 → 002 → 003 순)를 가리키고, 한 세트를 제출하면 다음 세트로 바뀐다
- [ ] '맞춤 세트 만들기' → 답안지 40칸, 총칙 → 물권 → 계약 순으로 문항이 나온다. 제출 후 최근 기록에 '맞춤 모의고사'로 남는다
- [ ] 설정의 '약점 단원 가중치'를 껐다 켜도 맞춤 세트가 정상적으로 만들어진다

## 8. 오답노트 · 통계

- [ ] 제출 직후 오답노트 "진행 중"에 틀린 문항이 있고 다음 복습이 "내일"
- [ ] 별표·메모 저장 후 앱을 껐다 켜도 남아 있다 (메모 입력 시 화면이 확대되지 않는다)
- [ ] 다음 날(또는 iPad 설정 → 일반 → 날짜 및 시간에서 날짜를 하루 뒤로 바꾼 뒤) "오늘 복습"에 나타난다 → 복습 → 맞힌 문항 "3일 후", 틀린 문항 "내일"
  - 날짜를 바꿨다면 테스트 후 **자동 설정으로 되돌린다**
- [ ] 홈: 연속 학습일, 오늘 복습 수, 약점 단원(3문항 이상 푼 단원)
- [ ] 통계: 점수 추이 점을 탭하면 점수·날짜가 보인다, 단원·유형별 막대

## 9. 설정 · 백업/복원

- [ ] 글자 크기 변경이 미리보기와 시험지에 바로 반영되고, 앱을 다시 열어도 유지된다
- [ ] 해설 즉시 보기 켜기 → 홈 버튼이 "연습 시작" → 보기를 고르면 바로 정답/해설, 답 변경 불가, 상단에 경과 시간
- [ ] **백업 파일 만들기** → 공유 시트가 열린다 → **파일에 저장** → iCloud Drive(또는 나의 iPad)에 `civil-exam-backup-….json` 저장됨
  - 공유 시트 대신 다운로드가 되면: 파일 앱 → 다운로드 폴더에 있는지 확인
- [ ] 시험을 하나 더 제출해 기록을 바꾼 뒤 **백업에서 복원…** → 파일 앱에서 백업 선택 → 요약·경고 확인 → 복원 → 앱이 다시 뜨고 백업 시점의 기록·설정으로 돌아간다
- [ ] 아무 JSON이 아닌 파일(사진 등)은 선택이 안 되거나 "이 앱의 백업 파일이 아닙니다"가 뜬다

## 10. 업데이트

- [ ] 새 버전을 같은 주소에 배포한 뒤 홈 화면 앱을 **두 번** 껐다 켜면 새 버전이 보인다 (자동 업데이트, 첫 실행에 받고 다음 실행에 적용될 수 있음)
- [ ] 업데이트 후에도 기록·오답노트·설정이 그대로다

## 알려진 제약

- 사파리 일반 탭으로만 쓰면 오래 열지 않은 사이트의 저장 데이터가 지워질 수 있다. **홈 화면에 추가**해서 쓰고, 백업 파일을 주기적으로 만든다.
- KoPubWorld바탕은 배포 조건상 번들하지 않았다. 기기에 설치돼 있지 않으면 나눔명조로 표시된다(`src/styles/fonts.css` 참고).
- 시드 5문항은 기획안 7절의 분량 기준보다 짧다(`npm run validate` 경고). 실전 세트(7단계)에서 기준에 맞춘다.
