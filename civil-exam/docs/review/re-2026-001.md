계산형(calc)은 `npm run validate`가 풀이 함수(src/solvers)로 정답·오답 보기를 이미 검사했다. 사람은 **발문 조건과 해설 내용**을 확인하고 `npm run mark -- <문항id>`로 검수 완료 표시한다(계산 검증이 실패하면 표시되지 않는다).

- 정답이 **하나뿐**인가 — 발문에 빠진 조건(완전경쟁, 단기/장기, 정상재 등)이 없는가
- 보기별 해설의 옳고 그름이 정답과 맞는가, 풀이 단계가 맞는가
- 개념형은 교재(경제학원론·부동산학원론)와 대조했는가, 감정평가 관련 내용은 현행 「감정평가에 관한 규칙」과 맞는가
- 그래프·표가 발문과 맞는가

문항마다 아래를 확인한 뒤 `npm run mark -- <문항id>`로 검수 완료 표시, 판례는 `npm run mark -- <문항id> --case <번호>`로 확인 표시한다.

- 정답이 **하나뿐**인가 (다른 보기도 옳다/틀리다고 다툴 여지가 없는가)
- 보기별 해설의 옳고 그름이 정답과 맞는가
- 근거 조문을 국가법령정보센터(law.go.kr) 현행 민법과 대조했는가
- 판례 취지를 대법원 종합법률정보(glaw.scourt.go.kr)에서 확인했는가

## 4. [총론·경제·시장·부동산경제론 · 탄력성과 수요량 변화율 · 계산형 · 난이도 1] `re-2026-001-q04`

아파트 수요의 가격탄력성은 0.6, 소득탄력성은 0.4이다. 아파트 가격이 5% 상승하고 소득이 10% 증가할 때 아파트 수요량의 변화율은? (단, 가격탄력성은 절댓값이며 다른 조건은 일정하다.)

① 1% 감소  
② 1% 증가  
③ 3% 감소  
④ 4% 증가  
⑤ 7% 증가  

**정답 ②** — 수요량 변화율 = (−가격탄력성 × 가격변화율) + (소득탄력성 × 소득변화율)

- ① 부호를 반대로 계산하였다.
- ② (정답) 1% 증가. 정답.
- ③ 소득 효과를 빠뜨렸다.
- ④ 가격 효과를 빠뜨렸다.
- ⑤ 가격 효과의 부호를 더하였다.

풀이:
1. 가격 효과: $-0.6 \times 5\% = -3\%$

## 5. [총론·경제·시장·부동산경제론 · 거미집 모형 · 계산형 · 난이도 2] `re-2026-001-q05`

어느 부동산시장의 수요함수는 $Q_d = 200 - P$, 공급함수는 $Q_s = -40 + 2P$ 이다. 공급이 전기의 가격에 반응하는 거미집 모형에 관한 설명으로 옳은 것은? (단, $P$는 가격, $Q$는 수량이다.)

① 가격과 거래량은 균형점으로 수렴한다.  
② 가격과 거래량은 균형점에서 점점 멀어진다.  
③ 균형가격은 100이다.  
④ 균형거래량은 100이다.  
⑤ 균형거래량은 80이다.  

**정답 ②** — 수량을 가격의 함수로 쓸 때 공급의 기울기($dQ_s/dP$)가 수요의 기울기 절댓값보다 크면 공급이 더 탄력적이어서 발산한다.

- ① 수렴하려면 공급곡선이 더 가팔라야(가격-수량 평면) 한다.
- ② (정답) 수요곡선이 더 가파르므로 발산한다. 정답.
- ③ 균형가격은 80이다.
- ④ 균형거래량은 120이다.
- ⑤ 80은 균형가격이다.

풀이:
1. 균형: $200 - P = -40 + 2P \Rightarrow P = 80$, $Q = 120$
2. $|dQ_d/dP| = 1 < dQ_s/dP = 2$ → 가격-수량 평면에서 수요곡선이 더 가파르다
3. 따라서 발산형이다.

계산 검증: `cobweb` {"a":200,"b":1,"c":-40,"d":2} → 발산 (보기별 주장 판정) — npm run validate 통과 시 정답 확인됨

## 9. [총론·경제·시장·부동산시장·입지론 · 허프 모형 · 계산형 · 난이도 2] `re-2026-001-q09`

허프(Huff)의 확률모형에 따를 때, 소비자 2,000명이 거주하는 지역에서 점포 A를 이용하는 소비자 수는? (단, 공간(거리)마찰계수는 2이고, 소비자는 두 점포 중 한 곳만 이용한다.)


| 구분 | 점포 A | 점포 B |
| --- | --- | --- |
| 매장면적(㎡) | 3,000 | 4,000 |
| 거리(km) | 10 | 20 |


① 500명  
② 1,000명  
③ 1,200명  
④ 1,500명  
⑤ 1,800명  

**정답 ④** — 흡인력 = 매장면적 ÷ 거리$^{\lambda}$, 점포 A 이용확률 = A의 흡인력 ÷ 흡인력 합

- ① 점포 B의 이용객 수이다.
- ② 거리마찰계수를 반영하지 않으면 흡인력이 달라진다.
- ③ 매장면적만으로 비례 배분한 값과 다르다.
- ④ (정답) 이용확률 0.75, 1,500명. 정답.
- ⑤ 흡인력 계산이 틀렸다.

풀이:
1. 흡인력: A $= 3{,}000/10^2 = 30$, B $= 4{,}000/20^2 = 10$
2. A 이용확률 $= 30/40 = 0.75$

② 거래사례비교법은 비슷한 물건의 거래사례와 비교하여 사정보정, 시점수정, 가치형성요인 비교 등을 거쳐 가액을 산정한다.  
③ 수익환원법은 장래 기대되는 순수익이나 미래의 현금흐름을 환원하거나 할인하여 가액을 산정하는 방법이다.  
④ 공시지가기준법은 표준지공시지가를 기준으로 시점수정, 지역요인·개별요인 비교 등을 거쳐 토지의 가액을 산정한다.  
⑤ 수익분석법은 일반기업 경영에 의한 총수익을 분석한 순수익에 필요경비를 더하여 대상물건의 가액을 산정한다.

## 39. [감정평가·감정평가론 · 부동산 가격원칙 · 개념형 · 난이도 2] `re-2026-001-q39`

부동산 가격원칙에 관한 설명으로 옳은 것은?

① 최유효이용의 원칙은 부동산 가격원칙 가운데 중추적인 원칙이다.  
② 적합의 원칙은 부동산 내부 구성요소 사이의 균형을 중시하는 원칙이다.  
③ 균형의 원칙은 부동산과 외부 환경 사이의 조화를 중시하는 원칙이다.  
④ 기여의 원칙은 부동산 가격이 구성요소의 생산비 합계와 항상 같다는 원칙이다.  
⑤ 예측의 원칙은 부동산 가격이 과거의 이용 실적만으로 결정된다는 원칙이다.  

**정답 ①** — 균형의 원칙은 내부 구성요소의 조화(기능적 감가와 관련), 적합의 원칙은 외부 환경과의 조화(경제적 감가와 관련)를 말한다.

- ① (정답) 최유효이용 원칙이 중추적 원칙이다. 정답.
- ② 내부 구성요소 간 균형은 균형의 원칙이다.
- ③ 외부 환경과의 조화는 적합의 원칙이다.
- ④ 기여의 원칙은 각 구성요소가 전체 가격에 기여하는 정도를 말하며 생산비 합계와 같지 않다.
- ⑤ 예측의 원칙은 장래의 수익성·쾌적성 등을 예측해 가격이 결정된다는 원칙이다.
