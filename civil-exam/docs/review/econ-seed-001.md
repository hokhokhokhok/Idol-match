# econ-seed-001 검수 시트

7문항 · 검수 완료 0 · 판례 확인 0/0

계산형(calc)은 `npm run validate`가 풀이 함수(src/solvers)로 정답·오답 보기를 이미 검사했다. 사람은 **발문 조건과 해설 내용**을 확인하고 `npm run mark -- <문항id>`로 검수 완료 표시한다(계산 검증이 실패하면 표시되지 않는다).

- 정답이 **하나뿐**인가 — 발문에 빠진 조건(완전경쟁, 단기/장기, 정상재 등)이 없는가
- 보기별 해설의 옳고 그름이 정답과 맞는가, 풀이 단계가 맞는가
- 개념형은 교재(미시·거시 원론)와 대조했는가
- 그래프·표가 발문과 맞는가

문항마다 아래를 확인한 뒤 `npm run mark -- <문항id>`로 검수 완료 표시, 판례는 `npm run mark -- <문항id> --case <번호>`로 확인 표시한다.

- 정답이 **하나뿐**인가 (다른 보기도 옳다/틀리다고 다툴 여지가 없는가)
- 보기별 해설의 옳고 그름이 정답과 맞는가
- 근거 조문을 국가법령정보센터(law.go.kr) 현행 민법과 대조했는가
- 판례 취지를 대법원 종합법률정보(glaw.scourt.go.kr)에서 확인했는가

## 1. [미시·수요공급·탄력성·조세 · 수요의 가격탄력성과 총수입 · 계산형 · 난이도 1] `econ-seed-001-q01`

어떤 재화의 시장수요함수가 $Q = 200 - 4P$ 이다. 가격이 $P = 30$ 일 때, 이 재화의 수요의 가격탄력성(절댓값)과 이 가격에서 가격을 소폭 인상할 경우 총수입의 변화를 옳게 짝지은 것은? (단, $Q$는 수요량, $P$는 가격이다.)

① 0.5, 증가  
② 1.0, 불변  
③ 1.5, 감소  
④ 1.5, 증가  
⑤ 2.0, 감소  

**정답 ③** — 점탄력성은 $|dQ/dP| \times P/Q$ 이고, 탄력적(>1)이면 가격 인상 시 총수입이 감소한다.

- ① 탄력성 계산 오류(0.5). 가격 인상 시 총수입 증가도 틀리다.
- ② 탄력성이 1이 아니다.
- ③ (정답) 탄력성 1.5, 탄력적이므로 가격 인상 시 총수입 감소. 정답.
- ④ 탄력성은 맞지만 탄력적인 구간에서는 총수입이 증가하지 않는다.
- ⑤ 탄력성이 2.0이 아니다.

풀이:
1. $P = 30$일 때 $Q = 200 - 4 \times 30 = 80$
2. 수요의 가격탄력성 $= 4 \times 30 / 80 = 1.5$
3. 탄력성이 1보다 크므로(탄력적) 가격을 올리면 총수입은 감소한다.

계산 검증: `linear-demand-elasticity` {"a":200,"b":4,"P":30} → 1.5 — npm run validate 통과 시 정답 확인됨

## 2. [미시·수요공급·탄력성·조세 · 종량세의 효과 · 계산형 · 난이도 2] `econ-seed-001-q02`

완전경쟁시장에서 어떤 재화의 시장수요곡선은 $Q_d = 100 - P$, 시장공급곡선은 $Q_s = P$ 이다. 정부가 공급자에게 재화 1단위당 10의 종량세를 부과할 때, 이에 관한 설명으로 옳은 것은? (단, $P$는 가격, $Q$는 수량이다.)

① 조세 부과 후 균형거래량은 40이다.  
② 소비자가 실제로 지불하는 가격은 55이다.  
③ 생산자가 실제로 수취하는 가격은 50이다.  
④ 정부의 조세수입은 500이다.  
⑤ 조세 부과에 따른 자중손실은 50이다.  

**정답 ②** — 공급자에게 부과된 종량세는 공급곡선을 세액만큼 위로 이동시킨다.

- ① 균형거래량은 45이다.
- ② (정답) 소비자 지불가격은 55이다. 정답.
- ③ 생산자 수취가격은 45이다.
- ④ 조세수입은 450이다.
- ⑤ 자중손실은 25이다.

풀이:
1. 조세 부과 후 공급: $Q = P - 10$
2. 균형: $100 - P = P - 10 \Rightarrow P = 55,\ Q = 45$
3. 생산자 수취가격 $= 55 - 10 = 45$
4. 조세수입 $= 10 \times 45 = 450$
5. 자중손실 $= \frac{1}{2} \times 10 \times (50 - 45) = 25$

계산 검증: `per-unit-tax-linear` {"demandIntercept":100,"demandSlope":1,"supplyIntercept":0,"supplySlope":1,"tax":10} → 55 (보기별 주장 판정) — npm run validate 통과 시 정답 확인됨

## 3. [미시·소비자이론 · 콥-더글라스 효용함수의 효용극대화 · 계산형 · 난이도 2] `econ-seed-001-q03`

소비자 갑의 효용함수는 $U = XY$ 이고, 소득은 120, $Y$재의 가격은 3이다. $X$재의 가격이 2에서 4로 상승하였을 때, 이에 관한 설명으로 옳은 것은? (단, 갑은 효용을 극대화하며, $X$와 $Y$는 모두 소비한다.)

① 가격 상승 전 $X$재의 최적 소비량은 20이다.  
② 가격 상승 후 $X$재의 최적 소비량은 15이다.  
③ 가격 상승 후 $Y$재의 최적 소비량은 10으로 감소한다.  
④ 가격 상승 후의 효용수준은 가격 상승 전보다 높다.  
⑤ 가격 상승 시 $Y$재 소비량이 증가하므로 $Y$재는 $X$재의 대체재이다.  

**정답 ②** — $U = XY$의 수요함수는 $X = M/(2P_X)$, $Y = M/(2P_Y)$이므로 $X$재 가격이 올라도 $Y$재 소비량은 변하지 않는다.

- ① 상승 전 $X$재 소비량은 30이다.
- ② (정답) 상승 후 $X$재 소비량은 15이다. 정답.
- ③ $Y$재 소비량은 20으로 불변이다.
- ④ 효용은 600에서 300으로 감소한다.
- ⑤ 교차가격탄력성이 0이므로 대체재도 보완재도 아니다.

풀이:
1. 상승 전: $X = 120/(2 \times 2) = 30$, $Y = 120/(2 \times 3) = 20$, $U = 600$
2. 상승 후: $X = 120/(2 \times 4) = 15$, $Y = 20$, $U = 300$

계산 검증: `cobb-douglas-demand` {"income":120,"pxBefore":2,"pxAfter":4,"py":3} → 15 (보기별 주장 판정) — npm run validate 통과 시 정답 확인됨

## 4. [거시·국민소득·승수·IS-LM·AD-AS · 정부지출승수와 조세승수 · 계산형 · 난이도 2] `econ-seed-001-q04`

폐쇄경제 모형이 다음과 같다. 정부지출을 50 증가시킬 때의 균형국민소득 변화량과, 정부지출은 그대로 두고 정액세(조세)를 50 증가시킬 때의 균형국민소득 변화량을 옳게 짝지은 것은? (단, 물가는 고정되어 있다.)

$Y = C + I + G$, $C = 100 + 0.8(Y - T)$, $I = 200$, $G = 300$, $T = 250$

① +200, -200  
② +250, -200  
③ +250, -250  
④ +200, -160  
⑤ +250, -160  

**정답 ②** — 정부지출승수 $= 1/(1-c) = 5$, 정액세승수 $= -c/(1-c) = -4$.

- ① 지출승수는 4가 아니라 5이다.
- ② (정답) +250, -200. 정답.
- ③ 조세승수의 절댓값은 5가 아니라 4이다.
- ④ 지출 효과(+250)와 조세 효과(-200) 모두 맞지 않는 값이다.
- ⑤ 조세 효과가 -160이 아니다.

풀이:
1. 균형소득: $Y = 100 + 0.8(Y - 250) + 200 + 300 \Rightarrow 0.2Y = 400 \Rightarrow Y = 2000$
2. 정부지출 50 증가: $\Delta Y = 5 \times 50 = +250$
3. 정액세 50 증가: $\Delta Y = -4 \times 50 = -200$

계산 검증: `keynesian-multiplier` {"mpc":0.8,"deltaG":50,"deltaT":50} → 250,-200 — npm run validate 통과 시 정답 확인됨

## 5. [거시·화폐·금융 · 통화승수와 본원통화 · 계산형 · 난이도 1] `econ-seed-001-q05`

어떤 경제에서 민간의 현금통화비율(현금/예금)은 0.2, 법정지급준비율은 0.1이며, 은행은 초과지급준비금을 보유하지 않는다. 중앙은행이 본원통화를 50만큼 증가시킬 때 통화량($M1$)의 증가분은? (단, 다른 조건은 일정하다.)

① 100  
② 150  
③ 200  
④ 250  
⑤ 300  

**정답 ③** — 통화승수 $m = \dfrac{1 + c}{c + z}$

- ① 승수를 2로 계산한 경우이다.
- ② 승수를 3으로 계산한 경우이다.
- ③ (정답) 승수 4, 증가분 200. 정답.
- ④ 승수를 5로 계산한 경우이다.
- ⑤ 승수를 6으로 계산한 경우이다.

풀이:
1. $m = (1 + 0.2) / (0.2 + 0.1) = 1.2 / 0.3 = 4$
2. 통화량 증가분 $= 4 \times 50 = 200$

계산 검증: `money-multiplier` {"currencyDepositRatio":0.2,"reserveRatio":0.1,"deltaBase":50} → 200 — npm run validate 통과 시 정답 확인됨

## 6. [미시·시장이론 · 독점기업의 가격과 자중손실 · 그래프형 · 난이도 2] `econ-seed-001-q06`

어떤 독점기업이 직면하는 시장수요곡선은 $P = 100 - Q$ 이고, 한계비용은 $MC = 20$ 으로 일정하다. 그림은 수요곡선($D$), 한계수입곡선($MR$), 한계비용곡선($MC$)을 나타낸다. 이 독점기업의 이윤극대화 가격과 독점으로 인한 자중손실을 옳게 짝지은 것은? (단, 고정비용은 없고 가격차별은 불가능하다.)

① 가격 50, 자중손실 800  
② 가격 60, 자중손실 400  
③ 가격 60, 자중손실 800  
④ 가격 70, 자중손실 800  
⑤ 가격 80, 자중손실 1,600  

**정답 ③** — 독점은 $MR = MC$에서 산출량을 정하고, 수요곡선에서 가격을 정한다.

- ① 가격이 50이 아니다.
- ② 자중손실의 밑변·높이 계산이 틀렸다(400).
- ③ (정답) 가격 60, 자중손실 800. 정답.
- ④ 가격이 70이 아니다.
- ⑤ 가격 80은 $Q=20$에서의 값이며 $MR=MC$가 아니다.

그래프: P-Q, D [[0,100],[100,0]] / MR [[0,100],[50,0]] / MC [[0,20],[100,20]]

풀이:
1. $MR = 100 - 2Q = 20 \Rightarrow Q = 40$
2. 가격: $P = 100 - 40 = 60$
3. 완전경쟁 산출량: $P = MC \Rightarrow 100 - Q = 20 \Rightarrow Q = 80$
4. 자중손실 $= \frac{1}{2} \times (60 - 20) \times (80 - 40) = 800$

계산 검증: `monopoly-linear` {"demandIntercept":100,"demandSlope":1,"mc":20} → 60,800 — npm run validate 통과 시 정답 확인됨

## 7. [미시·소비자이론 · 기펜재와 열등재 · 조합형 · 난이도 1] `econ-seed-001-q07`

기펜재(Giffen good)에 관한 설명으로 옳은 것을 모두 고른 것은?

> <보 기>
> ㄱ. 기펜재는 열등재이다.  
> ㄴ. 모든 열등재는 기펜재이다.  
> ㄷ. 기펜재는 가격이 상승하면 수요량이 증가하는 재화이다.  
> ㄹ. 기펜재의 경우 가격 변화에 따른 대체효과의 크기가 소득효과의 크기보다 크다.  

① ㄱ, ㄴ  
② ㄱ, ㄷ  
③ ㄴ, ㄷ  
④ ㄴ, ㄹ  
⑤ ㄷ, ㄹ  

**정답 ②** — 기펜재는 소득효과가 대체효과를 압도하는 열등재이며 수요곡선이 우상향한다.

- ① ㄴ이 틀렸다. 기펜재는 열등재의 일부이다.
- ② (정답) ㄱ, ㄷ이 옳다. 정답.
- ③ ㄴ이 틀렸다.
- ④ ㄴ, ㄹ 모두 틀렸다.
- ⑤ ㄹ이 틀렸다. 기펜재는 (음의) 소득효과의 크기가 대체효과의 크기보다 크다.
