# re-seed-001 검수 시트

7문항 · 검수 완료 0 · 판례 확인 0/0

계산형(calc)은 `npm run validate`가 풀이 함수(src/solvers)로 정답·오답 보기를 이미 검사했다. 사람은 **발문 조건과 해설 내용**을 확인하고 `npm run mark -- <문항id>`로 검수 완료 표시한다(계산 검증이 실패하면 표시되지 않는다).

- 정답이 **하나뿐**인가 — 발문에 빠진 조건(완전경쟁, 단기/장기, 정상재 등)이 없는가
- 보기별 해설의 옳고 그름이 정답과 맞는가, 풀이 단계가 맞는가
- 개념형은 교재(경제학원론·부동산학원론)와 대조했는가, 감정평가 관련 내용은 현행 「감정평가에 관한 규칙」과 맞는가
- 그래프·표가 발문과 맞는가

문항마다 아래를 확인한 뒤 `npm run mark -- <문항id>`로 검수 완료 표시, 판례는 `npm run mark -- <문항id> --case <번호>`로 확인 표시한다.

- 정답이 **하나뿐**인가 (다른 보기도 옳다/틀리다고 다툴 여지가 없는가)
- 보기별 해설의 옳고 그름이 정답과 맞는가
- 근거 조문을 국가법령정보센터(law.go.kr) 현행 민법과 대조했는가
- 판례 취지를 대법원 종합법률정보(glaw.scourt.go.kr)에서 확인했는가

## 1. [투자·금융·부동산투자론 · 일시불의 내가계수 · 계산형 · 난이도 1] `re-seed-001-q01`

현재 1억원을 연 이자율 5%, 1년 단위 복리로 3년 동안 예치할 때 3년 후의 원리금 합계는? (단, 세금과 수수료는 없다.)

① 105,000,000원  
② 110,250,000원  
③ 115,000,000원  
④ 115,762,500원  
⑤ 116,000,000원  

**정답 ④** — 미래가치 = 현재가치 × 일시불의 내가계수 $(1 + r)^n$

- ① 1년 후 금액이다.
- ② 2년 후 금액이다.
- ③ 단리(5% × 3년)로 계산한 값이다.
- ④ (정답) 복리 3년 후 원리금. 정답.
- ⑤ 어림한 값이다.

풀이:
1. 일시불의 내가계수 $= (1.05)^3 = 1.157625$
2. $100{,}000{,}000 \times 1.157625 = 115{,}762{,}500$원

계산 검증: `time-value` {"r":0.05,"n":3,"amount":100000000} → 115762500 — npm run validate 통과 시 정답 확인됨

## 2. [투자·금융·부동산투자론 · 순현재가치와 수익성지수 · 계산형 · 난이도 2] `re-seed-001-q02`

다음 투자안의 현금흐름에 관한 설명으로 옳은 것은? (단, 할인율은 연 10%이고 현금흐름은 기말에 발생한다.)


| 구분 | 0년(기초) | 1년 말 | 2년 말 |
| --- | --- | --- | --- |
| 현금흐름 | −900만원 | 440만원 | 726만원 |


① 순현재가치(NPV)는 100만원이다.  
② 수익성지수(PI)는 1.2이다.  
③ 내부수익률(IRR)은 할인율 10%보다 낮다.  
④ 할인율 10%에서 이 투자안은 기각된다.  
⑤ 현금유입의 현재가치는 900만원이다.  

**정답 ①** — NPV = 현금유입의 현재가치 − 투자액, PI = 현금유입의 현재가치 ÷ 투자액. NPV > 0이면 IRR > 할인율이다.

- ① (정답) NPV는 100만원이다. 정답.
- ② PI는 약 1.11이다.
- ③ NPV가 양수이므로 IRR은 10%보다 높다.
- ④ NPV > 0이므로 채택된다.
- ⑤ 현금유입의 현재가치는 1,000만원이다.

풀이:
1. 현금유입의 현재가치 $= \dfrac{440}{1.1} + \dfrac{726}{1.1^2} = 400 + 600 = 1{,}000$
2. $NPV = 1{,}000 - 900 = 100$, $PI = 1{,}000 / 900 \approx 1.11$
3. NPV > 0이므로 IRR은 10%보다 높고 투자안은 채택된다.

계산 검증: `npv-irr` {"cf0":900,"n":2,"r":0.1,"cf1":440,"cf2":726} → 100 (보기별 주장 판정) — npm run validate 통과 시 정답 확인됨

## 3. [감정평가·감정평가론 · 원가법의 감가수정(정액법) · 계산형 · 난이도 1] `re-seed-001-q03`

건물의 재조달원가는 2억원, 경제적 내용연수는 50년, 경과연수는 10년, 내용연수 만료 시 잔가율은 10%이다. 정액법으로 감가수정한 이 건물의 적산가액은?

① 160,000,000원  
② 164,000,000원  
③ 168,000,000원  
④ 170,000,000원  
⑤ 180,000,000원  

**정답 ②** — 정액법 매년 감가액 = 재조달원가 × (1 − 잔가율) ÷ 경제적 내용연수

- ① 잔가율을 고려하지 않은 값이다.
- ② (정답) 적산가액 1억 6,400만원. 정답.
- ③ 감가액을 잘못 계산한 값이다.
- ④ 감가액을 잘못 계산한 값이다.
- ⑤ 잔가(2,000만원)를 빼지 않고 1년 감가만 뺀 듯한 값이다.

풀이:
1. 매년 감가액 $= 200{,}000{,}000 \times 0.9 / 50 = 3{,}600{,}000$원
2. 감가누계액 $= 3{,}600{,}000 \times 10 = 36{,}000{,}000$원
3. 적산가액 $= 200{,}000{,}000 - 36{,}000{,}000 = 164{,}000{,}000$원

계산 검증: `cost-approach` {"cost":200000000,"life":50,"elapsed":10,"residual":0.1} → 164000000 — npm run validate 통과 시 정답 확인됨

## 4. [투자·금융·부동산투자론 · 영업수지의 계산 · 계산형 · 난이도 2] `re-seed-001-q04`

어떤 임대용 부동산의 가능총소득은 연 1억원, 공실 및 대손충당금은 가능총소득의 5%, 영업경비는 연 2,000만원, 부채서비스액은 연 3,000만원이다. 이에 관한 설명으로 옳은 것은? (단, 기타소득은 없다.)

① 유효총소득은 1억원이다.  
② 순영업소득은 7,500만원이다.  
③ 세전현금흐름은 5,500만원이다.  
④ 부채감당률은 2.0이다.  
⑤ 영업경비비율(영업경비 ÷ 유효총소득)은 20%이다.  

**정답 ②** — 가능총소득 − 공실·대손 = 유효총소득, − 영업경비 = 순영업소득, − 부채서비스액 = 세전현금흐름. 부채감당률 = 순영업소득 ÷ 부채서비스액.

- ① 유효총소득은 9,500만원이다.
- ② (정답) 순영업소득은 7,500만원이다. 정답.
- ③ 세전현금흐름은 4,500만원이다.
- ④ 부채감당률은 2.5이다.
- ⑤ 영업경비비율은 약 21.1%이다.

풀이:
1. 유효총소득 $= 10{,}000 \times 0.95 = 9{,}500$만원
2. 순영업소득 $= 9{,}500 - 2{,}000 = 7{,}500$만원
3. 세전현금흐름 $= 7{,}500 - 3{,}000 = 4{,}500$만원, 부채감당률 $= 7{,}500 / 3{,}000 = 2.5$
4. 영업경비비율 $= 2{,}000 / 9{,}500 \approx 21.1\%$

계산 검증: `operating-cash-flow` {"pgi":10000,"vacancy":0.05,"opex":2000,"debtService":3000} → 7500 (보기별 주장 판정) — npm run validate 통과 시 정답 확인됨

## 5. [총론·경제·시장·부동산시장·입지론 · 허프의 확률모형 · 계산형 · 난이도 2] `re-seed-001-q05`

허프(Huff)의 확률모형에 따를 때, 어느 주거지역 소비자 1,000명 중 점포 A를 이용하는 소비자 수는? (단, 공간(거리)마찰계수는 2이고, 소비자는 세 점포 중 한 곳만 이용한다.)


| 구분 | 점포 A | 점포 B | 점포 C |
| --- | --- | --- | --- |
| 매장면적(㎡) | 1,000 | 2,000 | 4,500 |
| 거리(km) | 5 | 10 | 15 |


① 250명  
② 400명  
③ 500명  
④ 600명  
⑤ 800명  

**정답 ③** — 점포의 흡인력 = 매장면적 ÷ 거리$^{\lambda}$, 이용확률 = 그 점포의 흡인력 ÷ 흡인력의 합

- ① B 또는 C의 이용객 수이다.
- ② 거리마찰계수를 1로 계산한 값에 가깝다.
- ③ (정답) 이용확률 0.5, 500명. 정답.
- ④ 흡인력을 잘못 계산한 값이다.
- ⑤ 흡인력을 잘못 계산한 값이다.

풀이:
1. 흡인력: A $= 1{,}000/5^2 = 40$, B $= 2{,}000/10^2 = 20$, C $= 4{,}500/15^2 = 20$
2. A의 이용확률 $= 40 / 80 = 0.5$
3. A 이용 소비자 $= 1{,}000 \times 0.5 = 500$명

계산 검증: `huff-model` {"s1":1000,"d1":5,"s2":2000,"d2":10,"s3":4500,"d3":15,"lambda":2,"pop":1000} → 0.5 (보기별 주장 판정) — npm run validate 통과 시 정답 확인됨

## 6. [총론·경제·시장·부동산경제론 · 거미집 모형 · 그래프형 · 난이도 2] `re-seed-001-q06`

어떤 부동산시장의 수요함수는 $Q_d = 120 - 2P$, 공급함수는 $Q_s = P$ 이다. 그림은 이 시장의 수요곡선($D$)과 공급곡선($S$)을 나타낸다. 공급이 전기의 가격에 반응하는 거미집 모형에 관한 설명으로 옳은 것은? (단, $P$는 가격, $Q$는 수량이다.)

① 가격과 거래량은 균형점으로 수렴한다.  
② 가격과 거래량은 균형점에서 점점 멀어진다.  
③ 균형가격은 30이다.  
④ 균형거래량은 60이다.  
⑤ 균형가격은 60이다.  

**정답 ①** — 가격-수량 평면에서 공급곡선의 기울기 절댓값이 수요곡선보다 크면(공급이 수요보다 비탄력적) 거미집은 수렴한다.

- ① (정답) 공급곡선이 더 가파르므로 수렴한다. 정답.
- ② 발산형은 수요곡선이 더 가파른 경우이다.
- ③ 균형가격은 40이다.
- ④ 균형거래량은 40이다.
- ⑤ 균형가격은 40이다.

그래프: P-Q, D [[0,60],[120,0]] / S [[0,0],[60,60]]

풀이:
1. 균형: $120 - 2P = P \Rightarrow P = 40$, $Q = 40$
2. $P$ 축 기준 기울기: 수요 $|{-}1/2| = 0.5$, 공급 $1$ → 공급곡선이 더 가파르다
3. 따라서 수렴형이다.

계산 검증: `cobweb` {"a":120,"b":2,"c":0,"d":1} → 수렴 (보기별 주장 판정) — npm run validate 통과 시 정답 확인됨

## 7. [총론·경제·시장·부동산학 총론 · 부동산의 자연적 특성 · 조합형 · 난이도 1] `re-seed-001-q07`

토지의 자연적 특성에 관한 설명으로 옳은 것을 모두 고른 것은?

> ㄹ. 개별성으로 인해 부동산 사이의 대체가 완전하게 이루어진다.  

① ㄱ, ㄴ  
② ㄱ, ㄹ  
③ ㄴ, ㄷ  
④ ㄱ, ㄴ, ㄷ  
⑤ ㄴ, ㄷ, ㄹ

- ③ ㄱ도 옳으므로 빠진 것이 있다.
