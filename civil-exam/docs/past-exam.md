# 기출 정보 기록

감정평가사 1차 시험은 한국산업인력공단(Q-Net)이 시행하며, 1990년 제1회부터 해마다 한 번 치른다(2024년 제35회, 2025년 제36회, 2026년 제37회).
문항이 기출 문항이거나 기출을 고쳐 만든 것, 또는 기출과 같은 쟁점을 다룬 것이면 그 연도·회차·문항 번호를 문항에 기록한다.

## 현재 수록 문항 점검 (2026-10-24)

| 과목 | 문항(시드 포함) | 창작(`source: "original"`) | 기출 정보 기록 |
|---|---|---|---|
| 민법 | 165 | 165 | 0 |
| 경제학원론 | 127 | 127 | 0 |
| 부동산학원론 | 127 | 127 | 0 |
| 감정평가관계법규 | 126 | 126 | 0 |

수록된 545문항은 모두 이 앱을 위해 새로 쓴 **창작 문항**이다. 제작 원칙상 기출·학원 문항의 문장을 옮기지 않았으므로 **기출 문항(그대로 옮긴 문항)은 없다**.
기출과 쟁점이 겹치는 문항은 있을 수 있으나, 기출 원문(Q-Net 공개 문제·정답)과 대조하지 않은 채 연도·번호를 적으면 틀린 정보가 되므로 아직 기록하지 않았다.
사용자가 기출 원문과 대조한 뒤 아래 명령으로 기록한다.

## 기록 방법

```bash
npm run mark -- 2026-001-q01 --past 2024:35:3 --kind 유사 --note "태아의 권리능력, 같은 쟁점"
npm run mark -- law-2026-002-q05 --past 2025:36:12 --kind 변형
npm run mark -- 2026-001-q01 --past 2024:35:3 --undo     # 기록 삭제
```

- `--past 연도:회차:번호` — 회차·번호는 생략할 수 있다(`--past 2023`). 회차는 연도 − 1989와 맞는지 검사한다.
- `--kind` — `기출`(그 기출 문항 그대로), `변형`(기출을 고쳐 만든 문항), `유사`(같은 쟁점의 창작 문항, 기본값).
  `기출`로 기록하면 `source`가 `"past"`로 바뀐다. 기출 문항을 옮겨 쓸 때는 Q-Net 공개 문제의 이용 조건을 확인한다.
- 이 명령으로 기록하면 `verified: true`(대조 확인)로 저장된다. JSON에 직접 적을 때는 확인 전이면 `verified: false`로 둔다.

```json
"pastExam": [{ "year": 2024, "round": 35, "number": 3, "kind": "유사", "verified": true, "note": "같은 쟁점" }]
```

## 앱 표시

- 해설 맨 위에 **"2024년 제35회 1차 3번 유사"** 같은 배지가 붙는다(확인 전이면 "· 확인 필요").
- 홈 세트 목록에 기출·변형 문항 수(`기출·변형 n`)가 표시된다.
- 검수 시트(`npm run review-sheet`)의 문항마다 기출 정보가 나온다.
- `npm run validate`가 연도(1990~)·회차·번호(1~40)와 `source`/`kind` 짝을 검사한다.
