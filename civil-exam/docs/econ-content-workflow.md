# 경제학원론 문항 제작·검수 흐름

경제학원론은 **수식·그래프·계산 문제**가 많고, AI가 만든 계산 문제의 가장 큰 위험은 "정답이 틀린 문제"다.
그래서 계산형은 **풀이 코드로 정답을 검증**하고, 개념형은 사람이 교재와 대조한다.

```
① 단원별 생성 (Claude 세션) → ② npm run validate -- --strict (계산 검증 포함) → ③ 검수 시트로 사람 검수 → ④ npm run mark → ⑤ 빌드·배포
```

## 파일·설정

| 파일 | 내용 |
|---|---|
| `src/data/sets/econ-<연도>-<번호>.json` | 경제학원론 세트 (예: `econ-2026-001`) |
| `config/econ/exam.json` | 40문항·2.5점·과목당 40분(1교시 120분을 세 과목이 나눔)·과락 40점, **계산기 허용 여부(`calculator`, Q-Net 공고 확인 필요)** |
| `config/econ/blueprint.json` | 단원별 문항 수(시장이론 6 …), 세트마다 ±1 — **미시/거시 비율은 추정값이므로 보유 기출로 보정** |
| `config/econ/length.json` | 유형별 분량 기준 — 실제 시험지로 보정 |
| `src/solvers/*.ts` | 계산 문항 풀이 함수 (`index.ts`에 solverId 등록) |

## 문항 데이터 요점

- `subject: "경제학원론"`, `field: "미시" | "거시"`(단원과 맞아야 함), `unit`(blueprint의 11개 단원), `type: calc | concept | combo | graph | table`.
- 수식: `$…$`(인라인), `$$…$$`(블록) — KaTeX 문법. 변수는 이탤릭으로 그려진다. 천 단위 쉼표는 수식 안에서 `1{,}200`.
- 그래프: `figure` (`kind: "line-plot"`, `xLabel`, `yLabel`, `xMax`, `yMax`, `series[{name, points, dashed}]`, `marks`, `shades`). 좌표는 0 이상, `xMax`·`yMax` 이하.
- 표: 발문에 `<table>` (게임 보수행렬, 비교우위 표 등). 속성은 `colspan`·`rowspan`만.
- 해설: `summary`, 계산형은 `steps`(풀이 단계, 수식 가능), `perChoice` 5개.

## 계산 검증 (`calc`)

```json
"calc": { "solverId": "monopoly-linear", "params": { "demandIntercept": 100, "demandSlope": 1, "mc": 20 }, "expected": "60,800" }
```

`npm run validate`가 풀이 함수를 실행해 다음을 **오류로** 검사한다(오류가 있으면 빌드도, `npm run mark`의 검수 완료 표시도 막힌다).

1. 풀이 결과 = `expected` (쉼표로 여러 값, 앞부분만 적어도 됨: `1.5` 또는 `1.5,감소`)
2. **값 보기**(예: `가격 60, 자중손실 800`, `$Y = 1{,}200$, $r = 4$`, `0.5, 증가`): 정답 보기만 풀이 결과와 같고, 다른 보기는 우연히라도 같지 않으며, 보기 값끼리 서로 다르다. 정수로 적은 보기는 정확히 같아야 하고 소수로 적은 보기는 마지막 자리 반올림만 허용.
3. **문장 보기**(예: "소비자가 지불하는 가격은 55이다."): `calc.claims`에 보기별 주장을 적는다 — `{ "key": "consumerPrice", "value": 55 }`, 부등호는 `"op": ">"`. 풀이값으로 판정해 "옳은 것은?"이면 정답만 참, "옳지 않은 것은?"이면 정답만 거짓이어야 한다. 판정하지 않는 보기는 `null`(경고).

풀이 함수 목록(`src/solvers/index.ts`): 선형수요 탄력성, 소비자·생산자잉여, 호탄력성, 기대효용, 슈타켈버그, 최저가격, 라스파이레스 물가지수, 테일러 준칙, 성장회계, 오쿤의 법칙, 소국 관세, 이자율평가, 종량세 귀착, 가격상한, 콥-더글라스·완전보완재 효용극대화, 2차 비용함수, 쿠르노, 독점, 3급 가격차별, 2×2 게임 내쉬균형, 노동수요, 외부성, 공공재, 승수(정액세·비례세), IS-LM, GDP 디플레이터, 통화승수, 화폐수량설·피셔, 고용 통계, 솔로우, 비교우위, 구매력평가. 새 계산 유형은 함수를 추가하고 `src/solvers/solvers.test.ts`에 손 검산값 테스트를 넣는다.

## ① 생성 — 단원별로

> civil-exam/docs/econ-content-workflow.md 를 지켜 시장이론 6문항 JSON을 만들어줘. 계산형은 기존 풀이 함수를 쓰거나 새로 추가하고,
> 오답 보기는 흔한 계산 실수 값(부호 오류, 한계/평균 혼동, 공식 착오)으로 설계해줘. setId는 `econ-2027-001`, 끝나면 `npm run validate -- --strict`.

작성 규칙: 창작 문항만(`source: "original"`), 발문은 "~에 관한 설명으로 옳은 것은?"·"(단, ~이다.)" 형식, 개념형은 조건(완전경쟁·단기/장기·정상재 등)을 빠뜨리지 않기, 정답 번호 ①~⑤ 각 8개 안팎, 보기별 해설의 끝맺음(정답 "… 정답.", 옳지 않은 것 문항의 나머지 "… 옳다.")을 지켜 복수 정답 자동 검사가 동작하게 하기. 난이도는 계산형 1~2, 개념형 1~3.

## ③ 검수 · ④ 표시

```bash
npm run review-sheet -- econ-2026-001     # docs/review/econ-2026-001.md
npm run mark -- econ-2026-001-q01          # 검수 완료 (계산 검증 실패 시 거부)
```

계산형은 계산 자체가 코드로 확인되므로 **발문 조건과 해설**만 본다. 개념형은 미시·거시 원론 교재와 대조한다.
