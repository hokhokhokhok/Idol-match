# 조문 원문 (law-texts)

해설의 **근거 조문**을 누르면 여기 넣어 둔 조문 원문이 팝업으로 뜬다. 빌드에 포함되므로 오프라인에서도 보인다.
파일이 없으면 팝업에 '국가법령정보센터에서 보기' 링크만 나온다. (법령 본문은 저작권 보호 대상이 아니다 — 저작권법 제7조)

## 1차: 직접 넣기

1. `_template.json`을 복사해 `건축법-법.json`, `건축법-시행령.json`처럼 이름을 짓는다 (이름이 `_`로 시작하면 앱이 읽지 않는다).
2. `name`은 정식 법률명(시행령·시행규칙 제외), `instrument`는 `법`/`시행령`/`시행규칙`/`고시`.
3. law.go.kr에서 조문을 복사해 `articles`에 `"제2조": { "title": "정의", "text": "① …\n② …" }` 형식으로 넣고 `asOf`에 기준일을 적는다. 조 번호 키는 `제84조`, `제84조의2`, 별표는 `별표2`처럼 공백 없이.
4. `npm run build` (또는 dev 서버)로 확인.

문항의 `legalBasis.cite`가 "국토의 계획 및 이용에 관한 법률 시행령 제84조 제1항"이면 `name: "국토의 계획 및 이용에 관한 법률"`, `instrument: "시행령"` 파일의 `제84조`를 찾는다.

## 2차: 법제처 Open API로 받기

```bash
LAW_OC=<발급받은 ID> npm run fetch-law -- 건축법 "건축법 시행령"
LAW_OC=<발급받은 ID> npm run fetch-law -- --all     # 감관법 9개 법률의 법·시행령·시행규칙
```

- OC 값: [국가법령정보 공동활용](https://open.law.go.kr)에서 회원가입 → **OPEN API 활용 신청**(승인까지 시간이 걸림) 후 받은 ID. 신청 시 호출할 서버(PC) IP 등록이 필요할 수 있다.
- 앱(브라우저)에서 직접 API를 부르지 않고 이 스크립트로 미리 받아 두는 방식이다 — 키를 앱에 넣지 않고, 오프라인에서도 쓰기 위해.
- 이 스크립트는 공개된 API 형식(`lawSearch.do`, `lawService.do`, JSON)에 맞춰 작성했으나 **이 저장소의 개발 환경에서는 law.go.kr에 접속할 수 없어 실제 호출로 시험하지 못했다.** 처음 실행할 때 결과 파일의 조문 몇 개를 law.go.kr 화면과 대조하고, 형식이 다르면 스크립트를 고쳐야 한다.
