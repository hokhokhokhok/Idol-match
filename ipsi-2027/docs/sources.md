# 데이터 출처와 수집 방식 (Phase 1)

> 파일별 URL·수집일·sha256·쪽수는 [`data/download_log.csv`](../data/download_log.csv), 표 형태 요약은 [download_report.md](download_report.md).
> 원본 PDF는 `data/raw/`(git 제외, 약 270MB). `python -m scrapers.download` 로 언제든 다시 받을 수 있다.

## 신뢰도 순서 (기획안 9장)

공식(대학 입학처·대교협) > 미러(공식 파일 사본) > 학원 분석 > 유튜브·커뮤니티

## robots.txt 확인 결과 (2026-11-08)

- 입학처 첫 화면에 대해 `User-agent: *` 차단: **중앙대, 한국외대, 국민대, 서울과기대** → 이 4개교는 입학처 사이트를 자동으로 탐색하지 않음. 모집요강은 미러로 확보했고, 입결은 수동 확인 대상
- 다운로드 스크립트는 파일마다 robots.txt를 다시 확인하고, 막혀 있으면 받지 않고 `robots_blocked`로 기록
