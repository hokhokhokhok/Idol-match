## 4. 앱에 반영하는 방식

- 🟢 항목만 "확정"으로 표시하고 계산(F4·F5)에 기본값으로 사용
- 🟡 항목은 "검증 필요" 배지와 함께 보정 요인 후보로 노출, 기본 가중치는 보수적으로
- 🔴 항목은 기본 비활성. 사용자가 출처를 직접 입력하면 활성화
- 블로그(F10)는 🟡·🔴 수치를 넣으면 경고(가드레일), 🔴는 생성 차단 대상
