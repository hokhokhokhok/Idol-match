# 합격 가능성 판정 방법 (F5, Phase 4)

> 이 판정은 합격을 보장하지 않습니다. 계산 근거와 가정값을 모두 공개하고, 화면에서 조절할 수 있게 했습니다.

## 1. 기준 데이터

| 항목 | 내용 |
|---|---|
| 출처 | 대학 공식 입학전형 결과 PDF (현재 동국대 2024·2026학년도) → `data/parsed/results/dongguk.csv` (`python -m scrapers.parse_dongguk_results`) |
| 기준값 | 정시 일반전형 **최종등록자(2024: 최종합격자) 백분위 상위 80%**의 국어·수학·탐구 평균, 계열 가중 평균, 표준편차, 환산점수 평균 |
| 계열 판정 | 입결표 '평균' 열을 재현하는 가중치(인문 국35/수25/탐25, 자연 국25/수35/탐25 — 2027 정시요강 40쪽과 동일)로 자동 판정. 재현되지 않으면 '기타'(예체능) |
| 검증 | 경영대학 2026: (35×93.87 + 25×77.39 + 25×91.30)/85 = 88.27 = 입결표 평균 (`tests/test_admission.py`) |

**왜 환산점수가 아니라 백분위 평균인가:** 환산점수는 그해 산출식 기준이라 반영총점·가산점이 바뀌면 그대로 비교할 수 없습니다. 예) 동국대 다군 경영대학은 2026 입결 환산점수 689.55인데, 2027은 다군 반영총점이 900점으로 바뀌었습니다. 계열 가중 백분위 평균은 산출식 변화의 영향을 덜 받습니다. 대신 **영어·한국사가 빠져 있으므로** 영어 등급은 합격자 평균 등급과 따로 비교해 경고합니다.

## 2. 내 점수

정시 환산 탭에 저장한 백분위로 같은 가중치의 평균을 계산합니다 (탐구는 2과목 평균).

## 3. 환경 보정 (기준을 이동)

| 요인 | 기본 | 근거 수준 | 비고 |
|---|---|---|---|
| N수생 증가 | +0.2점 × 가중치 1.0 | 🟡 졸업생 지원자 +8.6% (보도) | 이동폭 0.2점은 **가정값** |
| 개편 전 마지막 해 안정 지원 | +0.2점 × 가중치 0 | 🔴 원출처 미확인, 반대 신호 보도 | 기본 꺼짐 |
| 모집인원 변화(이월 포함) | 1% 증가당 −0.01점 | 가정값 | 2027 인원·이월 인원 입력 시 |
| 경쟁률 변화 | 1% 상승당 +0.005점 | 가정값 | 원서 접수 후 입력 |

근거: [context.md](context.md)

## 4. 판정

z = (내 점수 − 보정 기준) ÷ max(표준편차, 0.5)

| 판정 | 기본 기준 |
|---|---|
| 안정 | z ≥ 0.5 |
| 적정 | −0.5 ≤ z < 0.5 |
| 소신 | −1.5 ≤ z < −0.5 |
| 위험 | z < −1.5 |

- '상위 80% 평균'은 실제 최저 합격선보다 높습니다. z가 음수여도 합격할 수 있으므로 기준은 보수적인 편입니다.
- 표준편차가 0.5보다 작은 모집단위는 0.5로 보정합니다. 모집인원 10명 미만은 변동이 크다고 경고합니다.
- 실시간 모의지원 데이터가 없으므로, 입시업체 모의지원 결과를 직접 적어 교차검증하는 칸을 둡니다.

## 5. 한계

- 입결이 있는 대학이 동국대뿐입니다. 다른 대학은 화면의 'CSV 가져오기'로 추가합니다(출처 URL·쪽수 필수, 로컬 저장).
- 모집단위 통폐합(예: 2024 경영학과·회계학과 → 2026 경영대학)은 이름이 달라 추세 비교에서 빠집니다.
- 보정 이동폭은 근거 수치가 없는 가정값입니다. 수능 직후 입시기관 분석이 나오면 이 표와 함께 갱신합니다.
