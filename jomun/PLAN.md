# 감정평가사 2차 「감정평가 및 보상법규」 조문 암기 트레이너 기획안

## 1. 목표
- 행정법 총론 + 개별법(토지보상법, 부동산공시법, 감정평가법 등)의 **핵심 조문을 통합 암기**해 답안에 바로 쓰는 수준까지 훈련
- 매일 정해진 분량을 **등급(A~D)에 따라 다른 주기**로 반복 → 시험일에 전 범위 회독 완료
- 아이패드(Safari, 홈 화면 추가)에서 오프라인으로도 동작

## 2. 핵심 개념: A/B/C/D 등급
| 등급 | 의미 | 기본 복습 주기(최대) |
|---|---|---|
| A | 매 회차 출제·답안의 뼈대가 되는 핵심 조문 (예: 보상 기준·가격시점·개발이익 배제) | 매일~2일 |
| B | 자주 출제되는 조문·요건 | 4일 |
| C | 가끔 출제, 쟁점 연결용 조문 | 7일 |
| D | 세부 숫자·절차 등 출제 가능성 낮음 | 14일 |

**등급 산정 점수(권장, 조문별 0~100점)**
- 기출 빈도 40% (최근 10개년 문제·모범답안에서의 인용 횟수, 최근 연도 가중)
- 답안 필수도 30% (모범답안에서 "근거 조문"으로 반드시 등장하는지)
- 쟁점 연결성 15% (여러 쟁점·판례와 엮이는지)
- 총평 언급 10% (학원 총평·출제경향 분석에서 중요 언급)
- 암기 난이도 5% (숫자·주체·기간 등 틀리기 쉬운 정도)
- 80↑ A / 60↑ B / 40↑ C / 그 외 D, 사용자가 수동 조정 가능

## 3. 학습 모드
1. **오늘 복습 (빈칸 인출)**: 조문에서 핵심어를 빈칸으로 가리고 직접 입력 → 정답 대조 → 자기평가(몰랐다/애매/알았다)
2. **A급 정독**: A급 조문 전체를 소리 내어 읽는 아침 루틴
3. (확장) **통합 연결 훈련**: 쟁점 하나에 필요한 조문 3~5개를 순서대로 떠올리기 (예: 손실보상 요건 → 헌법 23조 → 토지보상법 → 개별 조문)
4. (확장) **답안 목차 훈련**: 기출 문제를 보고 필요한 조문 목록을 먼저 작성
5. (확장) **약점 집중**: 최근 오답률 높은 조문만 모아 복습

## 4. 복습 알고리즘 (라이트너 변형)
- 박스 0~6, 박스별 간격 `[1,1,2,4,7,14,30]`일
- 실제 간격 = `min(박스 간격, 등급 최대 간격)`
- 알았다 → 박스+1 / 애매 → 유지 / 몰랐다 → 박스-2 + 세션 내 재출제
- 하루 최대 복습 수 설정(기본 30), 정렬: 등급 A 우선 → 낮은 박스 우선

## 5. 데이터 구조 (JSON)
```json
{
 "id": "bosang-67-1",
 "law": "토지보상법",
 "article": "제67조 제1항",
 "title": "보상액의 가격시점",
 "grade": "A",
 "text": "…{{빈칸}}…",
 "tags": ["가격시점"],
 "source": {"exams": ["제33회 법규 1번"], "note": "총평 언급"},
 "verified": true
}
```
학습 상태: `box`, `due`, `log[{d, r}]`

## 6. 콘텐츠 구축 파이프라인 (권장 순서)
1. **조문 원문**: 국가법령정보센터(law.go.kr) 공식 원문을 기준으로 입력 (법령은 저작권 보호 대상 아님). 암기 중 오류 방지를 위해 `verified` 플래그로 원문 대조 여부를 관리
2. **기출 분석**: 최근 10개년 기출 문제에서 인용·요구된 조문을 추출해 빈도표 작성
3. **등급 부여**: 위 점수식으로 1차 산정 → 사용자가 최종 조정
4. **빈칸 설계**: 요건·효과·주체·기간 등 "답안에서 틀리면 감점되는 어구" 위주로 `{{ }}` 지정
- 참고: 모범답안·학원 총평·교재 본문은 저작물이므로 **원문을 앱에 복사해 넣지 말고**, 본인이 정리한 빈도·메모(조문 번호, 쟁점 키워드)만 입력

## 7. 화면 (iPad 가로/세로 대응)
- 오늘: 복습 대기 수, 등급 분포 바, 시작 버튼
- 복습: 조문 카드(등급 뱃지·법령명·조문번호) + 빈칸 입력 + 평가 버튼
- A급 정독: 큰 글씨 목록
- 관리: JSON 가져오기/내보내기(백업), 등급 변경, 일일 한도
