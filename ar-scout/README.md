# AR Scout — 안드로겐 수용체 결합 예측 도구

화장품·생활화학 원료가 안드로겐 수용체(AR)에 결합할 가능성을 단계적으로 좁혀가는
도구 모음입니다. **세포실험 대상의 우선순위를 정하는 데까지가 이 도구의 역할입니다.**

---

## 4단계 워크플로

| 단계 | 도구 | 입력 | 출력 | 걸리는 시간 | 무엇을 거르나 |
|---|---|---|---|---|---|
| 1. 1차 선별 | `ar-scout.html` | 물질명 또는 SMILES, 최대 400건 배치 | pKi ± 오차, 작용/길항 추정, 포켓 접촉도 | 즉시 | 명백한 비결합 물질. 수백 건을 수십 건으로 |
| 2. 모델 강화 | `local/train_qsar.py` | ChEMBL AR 데이터 | `ar_reference.json`, `ar_model.pkl` | 10–30분 | 레퍼런스 28종 → 수천 종. 적용영역 `out` 비율을 줄임 |
| 3. 3차 검증 | `local/ar_dock.py` | 1단계 배치 결과 CSV | `results.csv`, 포즈, 접촉 잔기 | 리간드당 1–3분 | 2D로는 구분 못 하는 입체 충돌·앵커 불일치 |
| 4. 세포실험 | — | 3단계 통과 물질 | 전사활성 측정 | — | 실제 판정은 여기서만 |

2단계는 선택입니다. 1단계 결과의 적용영역 태그가 대부분 `in`이면 건너뛰어도 됩니다.

## 설치

웹앱은 설치가 필요 없습니다. `ar-scout.html` 파일 하나를 브라우저로 열거나
사내에 링크로 공유하면 됩니다. 의존성 0, 외부 요청 0이므로 **입력한 원료 구조는
외부로 나가지 않습니다.**

글꼴 Pretendard는 CDN에서 받아오지 않고 **base64로 파일 안에 들어 있습니다**
(가변 폰트 1종, 2.6 MB). 폰트 이름만 적어두고 로컬 설치를 기대하면 설치돼 있지
않은 PC에서 디자인이 무너지고, CDN을 쓰면 단일 파일·외부요청 0 조건이 깨지기
때문입니다. 그래서 번들이 2.8 MB입니다 — 사내 공유나 로컬 실행에는 문제없는
크기이고, 엔진·UI 코드는 여전히 100 KB 남짓입니다.

```bash
# 웹앱 다시 빌드 (소스를 고쳤을 때만)
cd web && python3 build.py          # -> ../ar-scout.html

# 웹앱 테스트
cd web
node test/test_descriptors.js   # 분자식·MW·logP
node test/test_layout.js        # 2D 좌표 품질
node test/test_predict.js       # leave-one-out 성능
node test/test_aromaticity.js   # 표기 불변성 (케쿨레 = 소문자)
node test/smoke.js              # 번들 렌더링 (build.py 먼저 실행)
```

로컬 파이프라인:

```bash
cd local
pip install -r requirements.txt

# smina는 파이썬 패키지가 아니라 별도 실행파일입니다 (PyPI에 없음)
conda install -c conda-forge smina

# conda가 없는 환경이라면 micromamba를 conda 패키지로 직접 받아 부트스트랩:
#   curl -sSLO https://conda.anaconda.org/conda-forge/linux-64/micromamba-2.10.0-0.tar.bz2
#   tar -xjf micromamba-2.10.0-0.tar.bz2 bin/micromamba
#   MAMBA_ROOT_PREFIX=$PWD/mm ./bin/micromamba create -y -p ./env -c conda-forge smina
#   ./env/bin/smina --version
# ar_dock.py에 --smina ./env/bin/smina 로 경로를 넘기면 됩니다.

python3 test_ar_dock.py         # PDB 파싱·박스·접촉 분석 (네트워크/RDKit/smina 불필요)
python3 test_pipeline.py        # 정제 규칙·모델 학습 (네트워크 불필요, RDKit·sklearn 필요)
python3 test_crosscheck.py      # 웹 엔진 전체를 RDKit과 대조 (node + RDKit 필요)
python3 test_dock_integration.py --smina <경로>   # 재도킹 통합 테스트 (smina + ProDy 필요)
```

`test_dock_integration.py`는 ProDy에 동봉된 실제 결정 구조(1PWC, 페니실린 결합
효소)로 **재도킹(redocking)** 을 돌립니다. 결정 구조의 리간드를 꺼내 3D를 새로
만들고 자기 자리에 다시 도킹해, 원래 위치를 되찾는지 봅니다. 네트워크가 필요
없어 도킹 설정이 멀쩡한지 언제든 확인할 수 있습니다.

## 1단계 — 웹앱

**단건 조회**는 한글/영문 물질명 사전(97종)과 SMILES 직접 입력을 모두 받습니다.
출력은 pKi 추정값과 오차범위, Ki 환산값, 작용/길항 판정, 적용영역 태그,
포켓 접촉도, 2D 구조식, 기술자, 판정 근거, 최근접 레퍼런스 5종입니다.

**배치 스크리닝**은 `이름,SMILES` 한 줄씩 또는 CSV 업로드를 받아 pKi 순으로
정렬합니다. 결과는 TSV로 복사해 그대로 3단계 입력으로 쓸 수 있습니다.

**레퍼런스 라이브러리** 탭에서 2단계가 만든 `ar_reference.json`을 붙여넣거나
업로드하면 read-across 기준이 교체됩니다. 파싱에 실패한 항목은 건너뛰고
몇 건이 적용됐는지 알려줍니다.

### 결과 읽는 법

**적용영역 태그를 pKi보다 먼저 보세요.**

| 태그 | 최근접 유사도 | 오차범위 | 해석 |
|---|---|---|---|
| `적용영역 내` | ≥ 0.55 | ±0.7 | 유사 레퍼런스가 있음. 수치를 신뢰할 수 있는 구간 |
| `적용영역 경계` | ≥ 0.35 | ±1.1 | 참고용. 순위는 쓸 만하지만 절대값은 믿지 말 것 |
| `적용영역 밖` | < 0.35 | ±1.6 | **수치를 읽지 말고 태그만 보세요.** 규칙 점수에 의존한 외삽 |

| pKi 구간 | Ki | 통상 해석 |
|---|---|---|
| ≥ 8.0 | ≤ 10 nM | 강한 결합. 3단계 필수 |
| 6.5 – 8.0 | 10–300 nM | 유의한 결합. 3단계 권장 |
| 5.0 – 6.5 | 0.3–10 µM | 약한 상호작용. 노출량에 따라 판단 |
| < 5.0 | > 10 µM | 결합 근거 약함 |

## 2단계 — `train_qsar.py`

```bash
python3 train_qsar.py                  # 수집 + 정제 + 레퍼런스 + 모델
python3 train_qsar.py --cache          # 받아둔 원본 JSON 재사용
python3 train_qsar.py --skip-model     # 레퍼런스 JSON만
python3 train_qsar.py --max-ref 1000
python3 train_qsar.py --scaffold-split # 스캐폴드 분할로 재평가
```

정제 규칙이 결과를 좌우합니다:

- `standard_relation`이 `>`, `<` 같은 부등호인 **절단 측정값은 버립니다.** 참값이
  보고된 숫자 너머에 있으므로 정확한 값과 함께 평균 내면 전체가 편향됩니다.
- `data_validity_comment`가 달린 항목도 버립니다.
- pChEMBL이 없으면 nM 값에서 `9 − log10(nM)`로 직접 계산하고, 2.0–12.0 범위
  밖은 제외합니다.
- 같은 구조의 여러 측정값은 **중앙값**으로 통합하고 최대−최소 편차를 note에 남깁니다.
- 상한에 걸리면 **상위 N개를 자르지 않고 0.5 log 구간별로 고르게 샘플링합니다.**
  활성 물질만 남기면 "결합하지 않는다"는 판정 능력이 사라지는데, 이 도구가
  실제로 받는 질문은 대부분 그쪽입니다.

### 교차검증 MAE가 0.5 log 미만이면 경고가 뜹니다

실험 재현성 자체가 ±0.5 log 수준이므로, 무작위 분할에서 그보다 좋은 점수가
나오면 **좋은 모델이 아니라 데이터 누수 신호**입니다. 같은 시리즈 유사체가
train/test 양쪽에 나뉘어 들어가 모델이 친화도 예측이 아니라 시리즈 인식으로
점수를 받은 것입니다. `--scaffold-split`으로 Murcko 스캐폴드 기반 `GroupKFold`
재평가를 돌리면 처음 보는 골격에 대한 실제 성능이 나옵니다.

`test_pipeline.py`가 이 현상을 합성 데이터셋(108종, 6개 스캐폴드)으로 재현합니다:

| 분할 방식 | MAE | RMSE | R² |
|---|---|---|---|
| 무작위 5-fold | 0.224 | 0.273 | **0.637** |
| 스캐폴드 GroupKFold | 0.450 | 0.544 | **−0.442** |

같은 데이터, 같은 모델인데 R²가 0.64에서 음수로 떨어집니다. 무작위 분할의
0.637은 모델이 친화도를 예측해서 받은 점수가 아니라 **이미 본 적 있는 스캐폴드를
알아봐서 받은 점수**였다는 뜻입니다. 음수 R²는 "평균값으로 찍느니만 못하다"는
의미이고, 처음 보는 골격에 대해서는 그게 실제 성능입니다. **그쪽이 진짜 숫자입니다.**

## 3단계 — `ar_dock.py`

```bash
python3 ar_dock.py --prepare                      # 2AM9 내려받아 분리
python3 ar_dock.py --smiles "CC12CCC3..." --name DHT
python3 ar_dock.py --csv shortlist.csv            # name,smiles 열 인식
python3 ar_dock.py --prepare --pdb 2OZ7           # T877A 변이체 (아래 주의)
```

**도킹 박스는 공결정 리간드 좌표에서 산출합니다.** 단백질만 보고 포켓 위치를
추측하는 것이 엉뚱한 공동에 도킹하는 가장 흔한 경로입니다. 결정 구조에 실제로
들어있는 리간드가 진짜 자리를 표시해 줍니다. 산출된 박스는 `box.json`에 남습니다.

웹앱과 **같은 잔기 체계**를 쓰므로 두 결과를 줄 단위로 대조할 수 있습니다.

### 앵커 조합별 의미

| A-ring (Gln711/Arg752) | D-ring (Asn705/Thr877) | 해석 |
|---|---|---|
| ✓ | ✓ | 전형적 AR 리간드 결합 양상 |
| ✓ | ✗ (또는 반대) | 한쪽 앵커만 충족 — 배향 불안정 가능 |
| ✗ | ✗ | 소수성 접촉만 — 특이적 결합 근거 약함 |

helix-12 접촉은 **잔기를 가려서** 읽어야 합니다. 작용제 형태(2AM9)에서는 Met895가
포켓 벽을 이루기 때문에 결합하는 거의 모든 리간드가 닿습니다 — 22종 패널에서 19종이
접촉했고 나이아신아마이드·판테놀까지 포함됐습니다. Leu880도 12종으로 작용제가 섞여
있습니다. 반면 **Ile899는 helix-12 바깥쪽에 있어 AF-2 표면 쪽으로 뻗는 리간드만
닿습니다** — 22종 중 5종만 접촉했고 그 5종이 전부 길항제였습니다. 그래서 길항 판정은
Ile899 접촉에만 겁니다(`H12_DISPLACEMENT`). 나머지 두 잔기는 접촉 목록에 보고만
하고 판정에는 쓰지 않습니다.

### affinity 구간별 해석

| affinity (kcal/mol) | 해석 |
|---|---|
| ≤ −10 | 강한 결합 포즈. 앵커 조합까지 맞으면 4단계로 |
| −10 ~ −8 | 유의한 포즈. 접촉 잔기를 직접 확인할 것 |
| −8 ~ −6 | 경계. 앵커가 없으면 비특이 결합일 가능성 |
| −6 ~ 0 | 약함, 위양성 의심 |
| ≥ 0 | **포켓에 배치 실패.** 반발항이 지배한 것이므로 "약한 결합"이 아니라
  이 수용체 형태에 들어가지 않는다는 뜻입니다. 접촉 잔기 목록은 의미가 없으니
  읽지 마세요. 길항 형태 구조에서 재시도해야 합니다 |

**이 구간표는 포즈의 물리적 타당성을 보는 용도이지 순위표가 아닙니다.** 아래
실측 결과를 보면 affinity와 실측 pKi의 상관은 이 패널에서 사실상 없습니다.

## 실행 결과 — 실제로 돌려본 숫자

아래는 추정이 아니라 이 저장소의 스크립트를 그대로 돌려 나온 값입니다.

### 2단계 — ChEMBL (CHEMBL1871, 2026-11 기준)

```
14,838 raw  →  정제 후 5,450 측정 / 2,955 구조  →  계층 샘플링 2,500종
```

| 버려진 이유 | 건수 |
|---|---|
| Ki/IC50/Kd/EC50 이외 유형 | 7,855 |
| 부등호(절단) 관계 | 1,167 |
| 사용 불가 값·단위 | 347 |
| `data_validity_comment` | 17 |

**복제 측정 1,330건의 편차 중앙값이 0.52 log였습니다.** 이 도구가 내내 전제해 온
"실험 재현성 ±0.5 log"가 실측으로 확인된 셈이고, 그래서 교차검증 MAE가 0.5 log
아래로 내려가면 경고를 띄웁니다.

| 분할 | MAE | RMSE | R² |
|---|---|---|---|
| 무작위 5-fold | 0.514 | 0.677 | 0.646 |
| 스캐폴드 GroupKFold | 0.618 | 0.809 | **0.496** |

실제 데이터에서도 누수 효과가 나타나지만(R² 0.65 → 0.50) 합성 데이터만큼
극적이지는 않습니다. ChEMBL AR 데이터가 스캐폴드 다양성을 충분히 갖고 있기
때문입니다. **0.496이 처음 보는 골격에 대한 진짜 성능입니다.**

### ChEMBL 라이브러리를 그대로 교체하면 안 됩니다

받아보니 **2,500종 중 94%가 방향족(비스테로이드) 의약화학 시리즈**이고 스테로이드
유사 구조는 77종뿐이었습니다. 이걸로 기본 28종을 *교체*하면 DHT의 최근접 유사도가
0.34로 떨어져 **적용영역 밖**이 됩니다. 버그가 아니라 그 라이브러리에 대한 정확한
판정입니다 — 화장품 원료 스크리닝에서 중요한 스테로이드·단순 페놀류가 그 데이터에
거의 없습니다.

기본 28종 LOO / ChEMBL 2,500 / 둘을 **합친** 2,528종으로 같은 7종을 예측한 결과:

| 라이브러리 | 평균 절대오차 | DHT 적용영역 |
|---|---|---|
| 기본 28 (LOO) | 1.174 | in (1.00) |
| ChEMBL 2,500 | 1.050 | **out (0.34)** |
| 합친 2,528 | **0.991** | in (1.00) |

→ **교체하지 말고 합치세요.** 라이브러리 탭에서 `현재 라이브러리 JSON 보기`로
기본 28종을 복사한 뒤 `ar_reference.json` 내용을 뒤에 이어붙이면 됩니다.

### 3단계 — 2AM9 도킹 (22종, 2분 48초)

먼저 **결정 구조의 DHT가 웹앱 규칙이 예측하는 네 앵커와 정확히 수소결합**합니다.
잔기 체계가 맞다는 독립 확인입니다.

| 잔기 | 거리 | 역할 |
|---|---|---|
| Asn705 OD1 | 2.66 Å | D-ring |
| Arg752 NH2 | 2.82 Å | A-ring |
| Thr877 OG1 | 2.82 Å | D-ring |
| Gln711 NE2 | 3.21 Å | A-ring |

**그런데 affinity와 실측 pKi는 상관이 없었습니다 (r² = 0.03).** 22종 중 가장 좋은
점수를 받은 것이 에스트라디올(−11.3)인데 실측은 5.50으로 약한 리간드입니다.
2D 모델이 틀리는 항목을 도킹이 고쳐주지 못한 것입니다.

**도킹이 실제로 기여한 것은 순위가 아니라 배치 가능 여부였습니다.**

| 물질 | 실측 | 2D(LOO) | affinity | 판정 |
|---|---|---|---|---|
| Finasteride | 4.50 | 8.11 ✗ | **−0.8** | 배치 실패 → **2D 위양성을 도킹이 걸러냄** |
| Enzalutamide | 7.60 | 7.84 | **+9.2** | 배치 실패 → 작용제 형태의 한계 (실제로는 결합함) |
| Spironolactone | 7.20 | 8.06 | **−1.2** | 배치 실패 → 위와 같음 |

피나스테리드는 4-aza 스테로이드라 2D 유사도로는 DHT와 구분되지 않아 1단계가
8.11로 크게 틀립니다. 도킹에서는 아예 들어가지 않아 **3단계가 설계대로 작동한
유일한 사례**입니다. 반대로 엔잘루타미드·스피로노락톤은 실제 결합체인데 배치에
실패했습니다 — 2AM9가 작용제 형태라는 문서화된 한계가 그대로 드러난 것으로,
이 둘은 길항 형태(2OZ7 등)에서 다시 돌려야 합니다.

길항 판정(Ile899 접촉)은 비칼루타마이드·사이프로테론아세테이트·다롤루타미드·
RU-59063 4종에 발동했고 **전부 실제 길항제, 위양성 0건**이었습니다.

### 수용체 세 구조 비교 — 같은 22종

| | 2AM9 | 2OZ7 | 1Z95 |
|---|---|---|---|
| 공결정 리간드 | DHT | 사이프로테론아세테이트 | R-비칼루타마이드 |
| 변이 | **없음 (야생형)** | T877A | W741L |
| affinity ↔ pKi (r²) | 0.026 | **0.293** | 0.050 |
| 순위상관 (Spearman ρ) | +0.32 | **+0.54** | +0.30 |
| 배치 실패 | 1 (enzalutamide) | **0** | 2 (enzalutamide, finasteride) |
| Ile899 길항 판정 | **4종, 전부 길항제** | 6종, 작용제 3종 위양성 | 7종, DHT 위양성 |

세 구조 모두 순위 성능은 나쁩니다(최고가 r² 0.29). 그보다 중요한 건 **어느 구조를
고르느냐가 리간드보다 순위를 더 많이 좌우한다**는 사실입니다.

### 수용체가 자기 공결정 리간드 쪽으로 편향됩니다

| 구조 | 스테로이드 평균 순위 | 비스테로이드 평균 순위 | 자기 공결정 리간드 순위 |
|---|---|---|---|
| 2AM9 (DHT 결합) | 9.1 | 13.4 | 7 / 22 |
| 2OZ7 (CPA 결합) | 8.7 | 12.4 | 14 / 22 |
| 1Z95 (비칼루타마이드 결합) | **11.9** | **9.8** | **1 / 22** |

스테로이드가 결합한 두 구조에서는 스테로이드가 비스테로이드보다 앞서지만,
비칼루타마이드가 결합한 1Z95에서는 **순위가 뒤집히고 비칼루타마이드가 22종 중
1위**가 됩니다. 같은 분자의 점수가 구조만 바꿔도 이렇게 움직입니다:

| 리간드 | 2AM9 | 2OZ7 | 1Z95 |
|---|---|---|---|
| 비칼루타마이드 | −6.70 | −8.20 | **−10.20** |
| 다롤루타미드 | −6.10 | −7.30 | **−9.50** |
| DHT | **−9.90** | −9.00 | −6.00 |
| 메트리볼론 | **−11.70** | −10.30 | −9.30 |

비칼루타마이드 3.5 kcal/mol, DHT 3.9 kcal/mol 차이입니다. 리간드를 바꿔서 생긴
차이가 아니라 **수용체를 바꿔서 생긴 차이**입니다. 수용체를 rigid로 고정하는 한
공결정 리간드의 형태가 포켓에 새겨져 있고, 그 모양에 맞는 화학종이 유리해집니다.

**실무 지침:** 한 구조의 순위만 보고 판단하지 마세요. 세 구조에 모두 돌려
**순위가 아니라 일관성**을 보십시오 — 어디서든 상위권이면 신호이고, 구조마다
순위가 크게 뒤집히면 그 물질은 도킹으로 판단할 수 없다는 뜻입니다.
1Z95에서 비칼루타마이드가 1위인 것은 성능이 아니라 **재도킹에 가까운 자기
확인**이므로 그 자체로는 아무것도 증명하지 않습니다(파이프라인이 정상 동작한다는
것 외에는).

### 변이 자동 감지

AR LBD 구조 중 비스테로이드 리간드를 가진 것은 대부분 점변이체입니다.
`--prepare`가 이제 `SEQADV`를 읽어 알려주고, 변이가 앵커 잔기에 걸리면 따로
경고합니다.

```
2AM9 →  (없음)
2OZ7 →  NOTE: engineered mutation(s) in this entry: THR877ALA
        WARNING: THR877 (D-ring): structure has ALA877 - mutated, so this anchor can never match
1Z95 →  NOTE: engineered mutation(s) in this entry: TRP741LEU
```

## 한계 — 솔직하게

**도킹 점수는 친화도 예측값이 아닙니다.** 문헌에서 흔히 r² 0.3–0.5로 인용되지만,
이 저장소의 22종 패널(2AM9, 실측 pKi 4.0–9.5)에서 실제로 측정해 보니 **r² = 0.03**
(배치 실패 1건 제외 시 0.15)로 사실상 상관이 없었습니다. 점수 차이 0.5 kcal/mol로
두 물질의 우열을 가르는 것은 물론이고, **순위 자체를 신뢰해서도 안 됩니다.**
도킹이 실제로 기여한 것은 순위가 아니라 범주형 판정이었습니다 — 들어가는가,
어느 잔기에 닿는가. 자세한 수치는 아래 「3단계 실행 결과」를 보세요.

- **2AM9는 작용제 결합 형태입니다.** 엔잘루타미드처럼 helix-12를 밀어내는
  길항제는 이 구조에 제대로 들어가지 않습니다. 실측으로 엔잘루타미드 +9.2,
  스피로노락톤 −1.2로 **배치 자체가 실패**했습니다(둘 다 실제로는 결합체).
- **그렇다고 변이체 구조가 대안인 것은 아닙니다.** AR은 ER처럼 helix-12가 밀려난
  고전적 길항 형태 LBD 구조가 마땅치 않고, 비스테로이드 리간드가 들어간
  구조들은 대부분 **점변이체**입니다(2OZ7 = T877A, 1Z95 = W741L).
  2OZ7은 T877A 변이체에 사이프로테론아세테이트가 결합한 구조이고,
  **Thr877이 Ala877이라 D-ring 앵커 하나가 아예 존재하지 않습니다.**
  스크립트가 이제 이를 경고로 알려줍니다. 변이 포켓에 대한 답이지
  야생형에 대한 답이 아니라는 점을 염두에 두세요.
- **수용체를 rigid로 고정합니다.** 곁사슬이 움직여야 들어가는 리간드는
  과소평가됩니다. smina의 `--flexdist` / `--flexdist_ligand` 옵션으로 포켓 주변
  곁사슬을 유연하게 두고 재실행해 보세요.
- **구조수를 제거합니다.** Arg752 매개 수분자가 중요한 리간드는 영향을 받습니다.
- **대사 활성화를 모릅니다.** flutamide는 전구체이고 활성은 hydroxyflutamide에
  있는데 2D 구조가 거의 같아, 1단계에서 flutamide가 2 log 이상 과대평가됩니다.
- **4-aza 스테로이드를 오분류합니다.** finasteride는 5α-환원효소 억제제이지
  AR 리간드가 아니지만 2D 유사도로는 DHT와 구분되지 않습니다. 이 항목은
  3단계 도킹이 실제로 걸러냅니다(배치 실패).
- **에스트라디올은 3단계로도 안 고쳐집니다.** 1단계가 +2.5 log 과대평가하는데
  도킹에서도 22종 중 가장 좋은 점수(−11.3)를 받습니다. 실측은 5.50입니다.
  스테로이드 코어가 포켓에 잘 맞는 것은 사실이고, AR에서 약한 이유는 A-ring
  방향족화에 따른 전자적 차이라 형태 기반 평가로는 잡히지 않습니다.
- **입체화학을 무시합니다.** 1단계 파서는 키랄리티·동위원소 표기를 읽기만 하고
  값은 쓰지 않으므로 거울상 이성질체가 같게 평가됩니다. 반면 방향족성은
  인식하므로 케쿨레 표기(PubChem의 Canonical SMILES 형식)와 소문자 표기는
  같은 결과를 냅니다.
- **금속 함유·고분자·혼합물은 범위 밖입니다.** 징크피리치온 같은 금속 배위
  화합물은 기술자 자체를 신뢰할 수 없습니다.

**모든 결과는 세포실험 전 우선순위 선별용입니다. 규제 제출이나 안전성 판정의
근거로는 사용할 수 없습니다.**
