# AR Scout — 안드로겐 수용체 결합 예측 도구

화장품·생활화학 원료가 안드로겐 수용체(AR)에 결합할 가능성을 단계적으로 좁혀가는
도구 모음입니다. **세포실험 대상의 우선순위를 정하는 데까지가 이 도구의 역할입니다.**

---

## 4단계 워크플로

| 단계 | 도구 | 입력 | 출력 | 걸리는 시간 | 무엇을 거르나 |
|---|---|---|---|---|---|
| 1. 1차 선별 | `ar-scout.html` | 물질명 또는 SMILES, 최대 400건 배치 | pKi ± 오차, 작용/길항 추정, 포켓 접촉도 | 즉시 | 명백한 비결합 물질. 수백 건을 수십 건으로 |
| 2. 모델 강화 | `local/train_qsar.py` | ChEMBL AR 데이터 | `ar_reference.json`, `ar_model.pkl` | 10–30분 | 레퍼런스 28종 → 수천 종. 적용영역 `out` 비율을 줄임 |
| 3. 3차 검증 | `local/ar_dock.py` | 1단계 배치 결과 CSV | `results.csv`, 포즈, 접촉 잔기 | 리간드당 1–3분 | 2D로는 구분 못 하는 입체 충돌·앵커 불일치 |
| 4. 세포실험 | — | 3단계 통과 물질 | 전사활성 측정 | — | 실제 판정은 여기서만 |

2단계는 선택입니다. 1단계 결과의 적용영역 태그가 대부분 `in`이면 건너뛰어도 됩니다.

## 설치

웹앱은 설치가 필요 없습니다. `ar-scout.html` 파일 하나를 브라우저로 열거나
사내에 링크로 공유하면 됩니다. 의존성 0, 외부 요청 0이므로 **입력한 원료 구조는
외부로 나가지 않습니다.**

메일 첨부 용량이 빡빡하면 `--no-font`로 빌드한 **경량 버전**을 쓰세요. 기능은
완전히 같고 0.7 MB이며, Pretendard가 설치된 PC에서는 보이는 것도 동일합니다.
없으면 시스템 기본 산세리프로 폴백합니다. 둘 다 외부 요청은 0건입니다.

글꼴 Pretendard는 CDN에서 받아오지 않고 **base64로 파일 안에 들어 있습니다**
(가변 폰트 1종, 2.6 MB). 폰트 이름만 적어두고 로컬 설치를 기대하면 설치돼 있지
않은 PC에서 디자인이 무너지고, CDN을 쓰면 단일 파일·외부요청 0 조건이 깨지기
때문입니다. 그래서 번들이 2.8 MB입니다 — 사내 공유나 로컬 실행에는 문제없는
크기이고, 엔진·UI 코드는 여전히 100 KB 남짓입니다.

```bash
# 웹앱 다시 빌드 (소스를 고쳤을 때만)
cd web && python3 build.py          # -> ../ar-scout.html       (약 3.4 MB)
cd web && python3 build.py --no-font # -> ../ar-scout-lite.html  (약 0.7 MB)

# 웹앱 테스트
cd web
node test/test_descriptors.js   # 분자식·MW·logP
node test/test_layout.js        # 2D 좌표 품질
node test/test_predict.js       # leave-one-out 성능
node test/test_aromaticity.js   # 표기 불변성 (케쿨레 = 소문자)
node test/smoke.js              # 번들 렌더링 (build.py 먼저 실행)
```

로컬 파이프라인:

```bash
cd local
pip install -r requirements.txt

# smina는 파이썬 패키지가 아니라 별도 실행파일입니다 (PyPI에 없음)
conda install -c conda-forge smina

# conda가 없는 환경이라면 micromamba를 conda 패키지로 직접 받아 부트스트랩:
#   curl -sSLO https://conda.anaconda.org/conda-forge/linux-64/micromamba-2.10.0-0.tar.bz2
#   tar -xjf micromamba-2.10.0-0.tar.bz2 bin/micromamba
#   MAMBA_ROOT_PREFIX=$PWD/mm ./bin/micromamba create -y -p ./env -c conda-forge smina
#   ./env/bin/smina --version
# ar_dock.py에 --smina ./env/bin/smina 로 경로를 넘기면 됩니다.

python3 test_ar_dock.py         # PDB 파싱·박스·접촉 분석 (네트워크/RDKit/smina 불필요)
python3 test_pipeline.py        # 정제 규칙·모델 학습 (네트워크 불필요, RDKit·sklearn 필요)
python3 test_crosscheck.py      # 웹 엔진 전체를 RDKit과 대조 (node + RDKit 필요)
python3 test_dock_integration.py --smina <경로>   # 재도킹 통합 테스트 (smina + ProDy 필요)
```

`test_dock_integration.py`는 ProDy에 동봉된 실제 결정 구조(1PWC, 페니실린 결합
효소)로 **재도킹(redocking)** 을 돌립니다. 결정 구조의 리간드를 꺼내 3D를 새로
만들고 자기 자리에 다시 도킹해, 원래 위치를 되찾는지 봅니다. 네트워크가 필요
없어 도킹 설정이 멀쩡한지 언제든 확인할 수 있습니다.

## 결합 장면 (3D)

단건 조회에 **「결합 장면 (2AM9 포켓)」** 섹션이 있습니다. 드래그로 회전합니다.

브라우저는 도킹을 할 수 없습니다. 그래서 여기 보이는 것은 **전부 미리 계산한
실제 데이터**입니다 — 포켓은 2AM9 결정 좌표에서 잘라낸 55개 잔기(379원자)이고,
리간드는 `build_pocket_scene.py`가 smina로 도킹한 실제 포즈입니다. 사전 등재
229종 중 202종이 배치에 성공했습니다(16종 배치 실패, 1종은 3D 생성 실패).

| 표시 | 의미 |
|---|---|
| 진한 파랑 잔기 | 수소결합 후보 (3.5 Å 이내, 양쪽 N/O/S) |
| 파랑 잔기 | 접촉 (4.5 Å 이내) |
| 회색 잔기 | 나머지 포켓 잔기 |
| 점선 | 결정 구조의 DHT (버튼으로 겹쳐보기) |

라벨은 **수소결합 후보와 앵커 잔기(Gln711·Arg752·Asn705·Thr877)만** 답니다.
접촉 잔기를 전부 쓰면 스무 개가 넘어 리간드를 가립니다.

**지어내지 않는 두 가지 경우가 있습니다.**

- **배치 실패** — 두타스테리드(+23.6), 아팔루타미드(+10.6), 엔잘루타미드(+9.3),
  케토코나졸(+5.6)은 2AM9에 들어가지 않습니다. 충돌한 포즈를 포켓 안에 그리면
  결합 장면처럼 보이지만 결과가 아니므로 **좌표를 아예 저장하지 않고** 사유를
  표시합니다. 앞의 셋은 실제 결합체이며, 2AM9가 작용제 형태라서 생기는 한계입니다.
- **사전에 없는 물질** — 포즈가 없다고 밝히고 포켓과 결정 DHT만 보여줍니다.
  포즈가 필요하면 `ar_dock.py --smiles …` 로 직접 계산하세요.

## 1단계 — 웹앱

**단건 조회**는 한글/영문 물질명 사전(97종)과 SMILES 직접 입력을 모두 받습니다.
출력은 pKi 추정값과 오차범위, Ki 환산값, 작용/길항 판정, 적용영역 태그,
포켓 접촉도, 2D 구조식, 기술자, 판정 근거, 최근접 레퍼런스 5종입니다.

**배치 스크리닝**은 `이름,SMILES` 한 줄씩 또는 CSV 업로드를 받아 pKi 순으로
정렬합니다. 결과는 TSV로 복사해 그대로 3단계 입력으로 쓸 수 있습니다.

**레퍼런스 라이브러리** 탭에서 2단계가 만든 `ar_reference.json`을 붙여넣거나
업로드하면 read-across 기준이 교체됩니다. 파싱에 실패한 항목은 건너뛰고
몇 건이 적용됐는지 알려줍니다.

### 결과 읽는 법

**적용영역 태그를 pKi보다 먼저 보세요.**

| 태그 | 최근접 유사도 | 오차범위 | 해석 |
|---|---|---|---|
| `적용영역 내` | ≥ 0.55 | ±0.7 | 유사 레퍼런스가 있음. 수치를 신뢰할 수 있는 구간 |
| `적용영역 경계` | ≥ 0.35 | ±1.1 | 참고용. 순위는 쓸 만하지만 절대값은 믿지 말 것 |
| `적용영역 밖` | < 0.35 | ±1.6 | **수치를 읽지 말고 태그만 보세요.** 규칙 점수에 의존한 외삽 |

| pKi 구간 | Ki | 통상 해석 |
|---|---|---|
| ≥ 8.0 | ≤ 10 nM | 강한 결합. 3단계 필수 |
| 6.5 – 8.0 | 10–300 nM | 유의한 결합. 3단계 권장 |
| 5.0 – 6.5 | 0.3–10 µM | 약한 상호작용. 노출량에 따라 판단 |
| < 5.0 | > 10 µM | 결합 근거 약함 |

## 2단계 — `train_qsar.py`

```bash
python3 train_qsar.py                  # 수집 + 정제 + 레퍼런스 + 모델
python3 train_qsar.py --cache          # 받아둔 원본 JSON 재사용
python3 train_qsar.py --skip-model     # 레퍼런스 JSON만
python3 train_qsar.py --max-ref 1000
python3 train_qsar.py --scaffold-split # 스캐폴드 분할로 재평가
```

정제 규칙이 결과를 좌우합니다:

- `standard_relation`이 `>`, `<` 같은 부등호인 **절단 측정값은 버립니다.** 참값이
  보고된 숫자 너머에 있으므로 정확한 값과 함께 평균 내면 전체가 편향됩니다.
- `data_validity_comment`가 달린 항목도 버립니다.
- pChEMBL이 없으면 nM 값에서 `9 − log10(nM)`로 직접 계산하고, 2.0–12.0 범위
  밖은 제외합니다.
- 같은 구조의 여러 측정값은 **중앙값**으로 통합하고 최대−최소 편차를 note에 남깁니다.
- 상한에 걸리면 **상위 N개를 자르지 않고 0.5 log 구간별로 고르게 샘플링합니다.**
  활성 물질만 남기면 "결합하지 않는다"는 판정 능력이 사라지는데, 이 도구가
  실제로 받는 질문은 대부분 그쪽입니다.

### 교차검증 MAE가 0.5 log 미만이면 경고가 뜹니다

실험 재현성 자체가 ±0.5 log 수준이므로, 무작위 분할에서 그보다 좋은 점수가
나오면 **좋은 모델이 아니라 데이터 누수 신호**입니다. 같은 시리즈 유사체가
train/test 양쪽에 나뉘어 들어가 모델이 친화도 예측이 아니라 시리즈 인식으로
점수를 받은 것입니다. `--scaffold-split`으로 Murcko 스캐폴드 기반 `GroupKFold`
재평가를 돌리면 처음 보는 골격에 대한 실제 성능이 나옵니다.

`test_pipeline.py`가 이 현상을 합성 데이터셋(108종, 6개 스캐폴드)으로 재현합니다:

| 분할 방식 | MAE | RMSE | R² |
|---|---|---|---|
| 무작위 5-fold | 0.224 | 0.273 | **0.637** |
| 스캐폴드 GroupKFold | 0.450 | 0.544 | **−0.442** |

같은 데이터, 같은 모델인데 R²가 0.64에서 음수로 떨어집니다. 무작위 분할의
0.637은 모델이 친화도를 예측해서 받은 점수가 아니라 **이미 본 적 있는 스캐폴드를
알아봐서 받은 점수**였다는 뜻입니다. 음수 R²는 "평균값으로 찍느니만 못하다"는
의미이고, 처음 보는 골격에 대해서는 그게 실제 성능입니다. **그쪽이 진짜 숫자입니다.**

## 3단계 — `ar_dock.py`

```bash
python3 ar_dock.py --prepare                      # 2AM9 내려받아 분리
python3 ar_dock.py --smiles "CC12CCC3..." --name DHT
python3 ar_dock.py --csv shortlist.csv            # name,smiles 열 인식
python3 ar_dock.py --prepare --pdb 2OZ7           # T877A 변이체 (아래 주의)
```

**도킹 박스는 공결정 리간드 좌표에서 산출합니다.** 단백질만 보고 포켓 위치를
추측하는 것이 엉뚱한 공동에 도킹하는 가장 흔한 경로입니다. 결정 구조에 실제로
들어있는 리간드가 진짜 자리를 표시해 줍니다. 산출된 박스는 `box.json`에 남습니다.

웹앱과 **같은 잔기 체계**를 쓰므로 두 결과를 줄 단위로 대조할 수 있습니다.

### 앵커 조합별 의미

| A-ring (Gln711/Arg752) | D-ring (Asn705/Thr877) | 해석 |
|---|---|---|
| ✓ | ✓ | 전형적 AR 리간드 결합 양상 |
| ✓ | ✗ (또는 반대) | 한쪽 앵커만 충족 — 배향 불안정 가능 |
| ✗ | ✗ | 소수성 접촉만 — 특이적 결합 근거 약함 |

helix-12 접촉은 **잔기를 가려서** 읽어야 합니다. 작용제 형태(2AM9)에서는 Met895가
포켓 벽을 이루기 때문에 결합하는 거의 모든 리간드가 닿습니다 — 22종 패널에서 19종이
접촉했고 나이아신아마이드·판테놀까지 포함됐습니다. Leu880도 12종으로 작용제가 섞여
있습니다. 반면 **Ile899는 helix-12 바깥쪽에 있어 AF-2 표면 쪽으로 뻗는 리간드만
닿습니다** — 22종 중 5종만 접촉했고 그 5종이 전부 길항제였습니다. 그래서 길항 판정은
Ile899 접촉에만 겁니다(`H12_DISPLACEMENT`). 나머지 두 잔기는 접촉 목록에 보고만
하고 판정에는 쓰지 않습니다.

### affinity 구간별 해석

| affinity (kcal/mol) | 해석 |
|---|---|
| ≤ −10 | 강한 결합 포즈. 앵커 조합까지 맞으면 4단계로 |
| −10 ~ −8 | 유의한 포즈. 접촉 잔기를 직접 확인할 것 |
| −8 ~ −6 | 경계. 앵커가 없으면 비특이 결합일 가능성 |
| −6 ~ 0 | 약함, 위양성 의심 |
| ≥ 0 | **포켓에 배치 실패.** 반발항이 지배한 것이므로 "약한 결합"이 아니라
  이 수용체 형태에 들어가지 않는다는 뜻입니다. 접촉 잔기 목록은 의미가 없으니
  읽지 마세요. 길항 형태 구조에서 재시도해야 합니다 |

**이 구간표는 포즈의 물리적 타당성을 보는 용도이지 순위표가 아닙니다.** 아래
실측 결과를 보면 affinity와 실측 pKi의 상관은 이 패널에서 사실상 없습니다.

## 실행 결과 — 실제로 돌려본 숫자

아래는 추정이 아니라 이 저장소의 스크립트를 그대로 돌려 나온 값입니다.

### 2단계 — ChEMBL (CHEMBL1871, 2026-11 기준)

```
14,838 raw  →  정제 후 5,450 측정 / 2,955 구조  →  계층 샘플링 2,500종
```

| 버려진 이유 | 건수 |
|---|---|
| Ki/IC50/Kd/EC50 이외 유형 | 7,855 |
| 부등호(절단) 관계 | 1,167 |
| 사용 불가 값·단위 | 347 |
| `data_validity_comment` | 17 |

**복제 측정 1,330건의 편차 중앙값이 0.52 log였습니다.** 이 도구가 내내 전제해 온
"실험 재현성 ±0.5 log"가 실측으로 확인된 셈이고, 그래서 교차검증 MAE가 0.5 log
아래로 내려가면 경고를 띄웁니다.

| 분할 | MAE | RMSE | R² |
|---|---|---|---|
| 무작위 5-fold | 0.514 | 0.677 | 0.646 |
| 스캐폴드 GroupKFold | 0.618 | 0.809 | **0.496** |

실제 데이터에서도 누수 효과가 나타나지만(R² 0.65 → 0.50) 합성 데이터만큼
극적이지는 않습니다. ChEMBL AR 데이터가 스캐폴드 다양성을 충분히 갖고 있기
때문입니다. **0.496이 처음 보는 골격에 대한 진짜 성능입니다.**

### ChEMBL 라이브러리를 그대로 교체하면 안 됩니다

받아보니 **2,500종 중 94%가 방향족(비스테로이드) 의약화학 시리즈**이고 스테로이드
유사 구조는 77종뿐이었습니다. 이걸로 기본 28종을 *교체*하면 DHT의 최근접 유사도가
0.34로 떨어져 **적용영역 밖**이 됩니다. 버그가 아니라 그 라이브러리에 대한 정확한
판정입니다 — 화장품 원료 스크리닝에서 중요한 스테로이드·단순 페놀류가 그 데이터에
거의 없습니다.

기본 28종 LOO / ChEMBL 2,500 / 둘을 **합친** 2,528종으로 같은 7종을 예측한 결과:

| 라이브러리 | 평균 절대오차 | DHT 적용영역 |
|---|---|---|
| 기본 28 (LOO) | 1.174 | in (1.00) |
| ChEMBL 2,500 | 1.050 | **out (0.34)** |
| 합친 2,528 | **0.991** | in (1.00) |

→ **교체하지 말고 합치세요.** `merge_library.py`가 이 병합을 해 줍니다. 단순히
이어붙이면 안 되는 이유가 있습니다: 큐레이션 28종 중 **20종이 ChEMBL에도 있고 그중
8종이 0.5 log 넘게 어긋납니다**(에스트라디올 5.50 vs 7.72). 중복으로 남겨두면
read-across가 한 구조에 대해 모순된 두 값을 평균 내게 됩니다. 그래서 구조
단위(분자식 + Morgan 지문)로 중복을 제거하고 **큐레이션 값을 우선**하며, ChEMBL
내부 중복(다롤루타미드 등 159건)은 중앙값으로 합칩니다. 결과는 2,349종입니다.

**이 병합본은 웹앱에 이미 내장돼 있습니다.** 레퍼런스 탭에서 「확장 2,349종」을
누르면 바로 바뀝니다.

### 3단계 — 2AM9 도킹 (22종, 2분 48초)

먼저 **결정 구조의 DHT가 웹앱 규칙이 예측하는 네 앵커와 정확히 수소결합**합니다.
잔기 체계가 맞다는 독립 확인입니다.

| 잔기 | 거리 | 역할 |

| Asn705 OD1 | 2.66 Å | D-ring |
| Arg752 NH2 | 2.82 Å | A-ring |
| Thr877 OG1 | 2.82 Å | D-ring |
| Gln711 NE2 | 3.21 Å | A-ring |

**그런데 affinity와 실측 pKi는 상관이 없었습니다 (r² = 0.03).** 22종 중 가장 좋은
점수를 받은 것이 에스트라디올(−11.3)인데 실측은 5.50으로 약한 리간드입니다.

**도킹이 실제로 기여한 것은 순위가 아니라 배치 가능 여부였습니다.**

| 물질 | 실측 | 2D(LOO) | affinity | 판정 |
|---|---|---|---|---|
| Finasteride | 4.50 | 8.11 ✗ | **−0.8** | 배치 실패 → **2D 위양성을 도킹이 걸러냄** |

피나스테리드는 4-aza 스테로이드라 2D 유사도로는 DHT와 구분되지 않아 1단계가
8.11로 크게 틀립니다. 도킹에서는 아예 들어가지 않아 **3단계가 설계대로 작동한
유일한 사례**입니다. 반대로 엔잘루타미드·스피로노락톤은 실제 결합체인데 배치에
실패했습니다 — 2AM9가 작용제 형태라는 문서화된 한계가 그대로 드러난 것으로,
이 둘은 길항 형태(2OZ7 등)에서 다시 돌려야 합니다.

길항 판정(Ile899 접촉)은 비칼루타마이드·사이프로테론아세테이트·다롤루타미드·
RU-59063 4종에 발동했고 **전부 실제 길항제, 위양성 0건**이었습니다.

## 레드팀 — AR 전문가 관점에서 자기 공격한 결과

도구가 어느 정도 자리를 잡은 뒤, 안드로겐 수용체 쪽 지식으로 이 저장소의 논리를
일부러 깨보았습니다. 아래는 **실제로 코드와 데이터에서 확인된** 허점과, 그에 대한
조치입니다. 추측으로 적은 항목은 없습니다.

### 치명 ① 길항성을 재지 않으면서 길항제 순위를 매기고 있었습니다 — 부분 해결

(공격 내용은 아래 그대로 두고, 그 뒤에 실제로 메운 부분을 적습니다.)

**메운 것: Tox21 AC50과 효력.** 이 어세이들은 활성 여부만이 아니라
`AR Potency (µM)`와 `AR Efficacy (%)`, 그리고 같은 웰의 `Viability Potency`를
함께 보고합니다. 즉 **세포에서 실제로 측정된 농도와 반응 크기**가 있습니다.
사전 206종 중 85종이 여기에 해당하고, 이제 단건 화면에 pKi보다 **위에** 띄웁니다.
친화도 추정이 효력을 대신하고 있던 자리를 실측이 채웁니다.

| 물질 | 길항 AC50 | 효력 | 생존 AC50 | 여유배수 |
|---|---|---|---|---|
| Cyproterone acetate | 1.28 µM | −93.7% | 43.6 µM | **×34** |
| Hydroxyflutamide | 1.90 µM | −77.5% | 29.8 µM | ×16 |
| Nilutamide | 3.47 µM | −67.8% | 49.0 µM | ×14 |
| Bicalutamide | 10.9 µM | −101% | 27.0 µM | ×2.5 |
| **Prochloraz** | 47.1 µM | −111% | 7.76 µM | **×0.16** |
| **Alfatradiol** | 44.9 µM | −121% | 36.7 µM | **×0.82** |

**효력 부호는 분류기로 쓰지 않습니다.** 라벨 20종에서 「효력 음수면 길항」은
**14/20**입니다 — 알려진 작용제 8종 중 5종도 이 웰에서 신호를 떨어뜨립니다.
기준 작용제와 경쟁하면 그렇게 되니까요. 숫자가 붙었다고 분류기가 되지는
않습니다.

**여유배수는 씁니다.** 기존의 이진 「세포독성」 플래그는 표시만 하고 아무것도
하지 않았습니다(비칼루타마이드도 세 웰 중 하나가 세포독성이라 강등에 쓰면
교과서적 길항제가 묻히므로). 이제 숫자가 있습니다. **프로클로라즈는 세포가 죽는
농도의 1/6에서 "길항" 신호를 냅니다.** 큐레이션 길항제 레퍼런스인데도요.

**그리고 작용제 모드가 더 센 경우를 잡습니다.** 알파트라디올은 작용제 모드
AC50 1.08 µM(효력 +96.5%)인데 길항은 44.9 µM — 40배 차이입니다. 명백한
작용제인데 길항제 순위에서 「우선 확인」에 있었습니다. 에스트라디올도 같습니다.
둘 다 최하 구간으로 내렸습니다.

**단, 큐레이션 라벨은 이깁니다.** 스피로놀락톤과 드로스피레논도 작용제 모드
활성이 세게 나오는데(스피로놀락톤은 AR 길항제이면서 프로게스테론 수용체
작용제입니다), 두 AC50으로 확립된 약리를 뒤집지는 않습니다. 순위는 유지하고
불일치를 표시합니다.

**여전히 못 메운 것:** 85종 밖의 121종에는 이 축이 없습니다. 그리고 AC50은
세포 수준이지 helix-12 동역학이 아닙니다. 아래 원래 공격은 그대로 유효합니다.

### 치명 ① 길항성을 재지 않으면서 길항제 순위를 매기고 있었습니다

AR 길항성은 결합의 성질이 아니라 **결합 이후 helix-12가 무엇을 하느냐**의
성질입니다. 비칼루타마이드는 DHT보다 AR 친화도가 두 자릿수 배 낮지만 임상
길항제입니다. 이 도구의 친화도 탭도 정확히 그렇게 내놓습니다 — DHT 9.18,
비칼루타마이드 7.14.

**두 숫자 다 맞고, 길항 효력 순위로는 둘 다 쓸모없습니다.** efficacy 축이
아예 없습니다. 「길항제」로 찍힌 것의 실제 의미는 *"결합하고, 길항하는 것들과
닮았다"* 입니다.

**조치:** 두 순위 탭 상단에 빨간 글씨로 *"이것은 효력 순위가 아닙니다"* 와
노출 축 부재(pKi 5 = Ki 10 µM, 피부에서 그 농도가 표적에 닿는지는 모델 밖)를
고정 표기했습니다. 축을 만들 수 없으므로 **없다고 적는 것**이 유일하게 정직한
조치입니다.

### 치명 ② 내성 변이체 Δ는 교차결정 아티팩트였습니다 — 재실험으로 확인

README 자신이 반박하고 있었습니다. 「어느 구조를 고르느냐가 리간드보다 순위를 더
많이 좌우한다」, 「1Z95는 자기 공결정 리간드를 22종 중 1위로 올린다」라고 적어
놓고, 그 1Z95의 공결정 리간드인 **R-비칼루타마이드의 ΔW741L = −3.5**를 "길항제
구제"의 대표 증거로 썼습니다. 자기도킹 편향입니다.

그래서 **통제 실험**을 했습니다. 같은 2AM9 결정에서 곁사슬만 in-silico로 잘라내,
백본·박스·해상도·나머지 249개 잔기를 전부 고정했습니다(바이트 단위로 동일함을
검증). Thr→Ala는 절단이 정확히 일치합니다.

| 클래스 | 옛 Δ (교차결정) | 새 Δ (동일결정) |
|---|---|---|
| agonist (16) | +0.71 | **+0.03** |
| antagonist (17) | −2.42 | **−0.51** |
| partial (5) | −1.28 | −0.60 |
| **분리폭** | **+3.14** | **+0.53** |

| 물질 | 옛 → 새 |
|---|---|
| Bicalutamide | −1.50 → **−0.10** |
| Spironolactone | −3.10 → **−0.50** |
| Testosterone | +2.40 → **+0.20** |
| Cyproterone acetate | −2.10 → −1.40 |

**분리폭이 83% 사라졌습니다.** 0.53 kcal/mol은 도킹 점수 오차 안입니다.
옛 주장은 돌연변이가 아니라 결정 구조 차이를 재고 있었습니다.

### 치명 ③ 코르티코스테로이드가 「AR 작용제 실측」으로 투표하고 있었습니다

read-across 실측 풀을 자동 규칙으로 만들고 **한 번도 눈으로 보지 않았습니다.**
확인해 보니 하이드로코르티손·프레드니솔론·코르티코스테론이 "측정된 AR 작용제"로
다른 물질의 기능을 투표하고 있었습니다. 세 어세이 중 하나가 MDA-kb2에서 도는데
그 리포터는 **MMTV-luc이고 MMTV는 GR 반응 요소**이며 그 세포주는 GR을
발현합니다. GR 작용제가 MMTV를 켜는 건 AR과 무관합니다.

풀 16종을 눈으로 보니 **8종의 주 수용체가 AR이 아니었습니다** — 5AR 억제제 1,
ER 2, GR 3, RAR 1, 전구체 1.

**조치:** 기전 제외 목록을 **사유와 함께 손으로** 작성했습니다. 리포터 숫자가
어느 수용체에서 나왔는지는 어세이 코드로 유도할 수 없고 약리 지식이 필요하기
때문입니다. 풀 16 → 10종, 큐레이션 38종 LOO는 32/38 그대로 — 오염이 성능을
떠받치고 있던 것은 아니었습니다.

풀에서 빼는 건 절반이었습니다. 하이드로코르티손 자신의 화면은 여전히
"AR 작용제 (실측)"이었습니다. 이제 **판정을 거부**하고 이유를 적습니다.
(처음엔 read-across로 흘려보냈는데 "길항제 가능성"이 나와 더 나빴습니다 —
글루코코르티코이드는 스테로이드를 닮았으니까요.)

### 중대 ④ 28종 레퍼런스에 출처가 없었습니다 — ChEMBL로 되짚음

어떤 어세이인지, 사람인지 랫인지 아무 기록 없이 한 척도로 섞어 놓고 MAE를
인용하고 있었습니다. ChEMBL에 직접 물어본 결과:

- AR 활성 **사람 273건 · 랫 44건 · 마우스 11건**
- **7종은 사람 AR 기록이 전혀 없음** (트렌볼론·메틸테스토스테론·p,p'-DDE·
  피나스테리드·판테놀·나이아신아마이드·난드롤론 — 랫·마우스뿐)
- **4종은 추적 실패** (DHT·빈클로졸린·부틸파라벤·카페인).
  **DHT는 이 라이브러리의 기준점입니다.**
- **빈클로졸린은 프로안티안드로겐**입니다. AR에 붙는 것은 대사체 M1·M2이지
  빈클로졸린이 아니라서, 이 pKi를 직접 결합값으로 읽으면 안 됩니다.

**조치:** 출처 등급을 번들에 넣고 UI의 모든 레퍼런스 옆에 표시합니다. 값이
틀렸다는 뜻은 아니지만, **MAE 0.5는 랫 전립선 세포질 결합과 사람 LBD 어세이를
같은 열에 섞은 채** 계산된 값이라고 적었습니다.

### 중대 ⑤ Ile899 규칙은 기전이 거꾸로입니다

2AM9는 작용제 형태 — helix-12가 포켓 뚜껑처럼 닫힌 구조이고, 도킹 중 수용체는
고정입니다. 진짜 길항제가 하는 **helix-12 밀어내기는 이 계산이 재현할 수 없는
동작**입니다(엔잘루타미드는 배치조차 실패). 그러니 "Ile899에 닿는다"가 잡는 것은
길항성이 아니라 **닫힌 뚜껑에 닿을 만큼 긴 분자**입니다. 위양성 0건이지만 n = 4.

그리고 그 접촉 목록은 **affinity 상관 r² = 0.03짜리 좌표**에서 나옵니다.
점수가 무상관이면 포즈 기하도 그만큼만 믿을 수 있습니다.

**조치:** 둘 다 접촉 패널과 포켓 판정에 그대로 적었습니다.

### 확인했으나 조치가 제한적인 것

- **적용영역.** 206종 중 129종이 밖입니다. 주 사용처(화장품 원료)가 곧 무효
  구간입니다. 확장 2,349종 라이브러리로 바꾸면 **밖이 101종으로 줄고 같은 28종
  자기제외 시험에서 MAE 0.84→0.77**로 나아집니다. 기본값을 조용히 바꾸지 않고
  측정값을 카드에 적어 한 번에 전환할 수 있게 했습니다 — 바꾸면 사용자가 이미
  본 모든 숫자가 함께 바뀌기 때문입니다.
- **작용/길항 이분법.** 남은 LOO 오답 6건 중 4건이 프로게스틴입니다. 우연이
  아니라 조직·보조활성인자 맥락 의존성이고, 「부분 작용제」 라벨 하나로는
  표현되지 않습니다. SARM류 조직선택성, AF-1/N말단, AR-V7은 전부 범위 밖입니다.

## 결합 친화도 탭 — 세기와 방향을 따로 봅니다

사전 206종을 예측 pKi 순으로 세우고, 작용제·길항제 판정을 나란히 붙입니다.
길항제만 / 작용제만 / 적용영역 밖 숨기기로 걸러집니다.

**두 질문을 한 점수로 합치지 않았습니다.** 「얼마나 세게 붙느냐」와 「어느
방향이냐」는 근거도 신뢰도도 다릅니다. 세게 붙으면서 아무 일도 안 하는 분자가
있습니다.

상위권은 메트리볼론(9.30)·트렌볼론(9.26)·DHT(9.18)·디에노게스트(9.05)·
난드롤론(8.94)으로, 실제 고친화도 AR 리간드와 맞습니다. pKi ≥ 8 구간에
작용제 19종과 길항제 7종이 함께 있습니다 — 친화도만으로는 방향을 알 수 없다는
뜻이고, 그래서 열을 나눠 둔 것입니다.

**적용영역 태그가 여기서 제일 중요합니다.** 가까운 레퍼런스가 없는 물질의 pKi는
외삽인데, pKi로 정렬하면 그 숫자가 어디에 떨어지든 그 자리에 앉습니다. 206종 중
`out`이 129종이라 기본값은 숨김입니다.

## 유도체 설계 탭 — 최적화기가 아니라 가설 생성기

길항제를 하나 고르면 그 분자의 열린 6원 방향족 자리마다 치환기를 붙여 유도체를
만들고, 같은 엔진으로 다시 채점합니다.

치환기는 지어내지 않았습니다. 전부 알려진 비스테로이드 항안드로겐이 실제로
갖고 있는 것입니다 — CF3(비칼루타마이드·엔잘루타미드·플루타마이드·닐루타미드),
나이트릴(비칼루타마이드·엔잘루타미드·아팔루타미드), 나이트로(플루타마이드·
닐루타미드), 메틸설포닐(비칼루타마이드). **그리고 대조군으로 메틸·하이드록실·
불소·염소를 일부러 섞었습니다.**

### 생성물 검증

SMILES writer가 없어서 문자열을 편집하는 방식입니다. 그래서 **규칙마다 자기가
만들 화학식 변화를 미리 선언하게 하고, 측정값이 다르면 보여주지 않고 버립니다.**
고리 수가 변해도 버립니다. ChEMBL에서 에스터·염이 섞여 들어왔을 때 쓴 것과 같은
장치입니다. 테스트는 일부러 틀린 규칙(CF3인데 F를 2개라고 선언)을 심어 두고
생성물이 하나도 새어 나오지 않는지 확인합니다.

치환 자리는 **6원 방향족 고리의 수소 남은 탄소**로 한정했습니다. 스테로이드
17번 치환처럼 길항성을 실제로 좌우하는 변형은 문자열 편집으로 안전하게 만들 수
없어 넣지 않았고, DHT처럼 방향족 고리가 없는 골격은 "유도체 0종"으로 끝납니다.

### 측정해 보니 — 이 탭이 할 수 있는 일과 없는 일

**점수를 매기는 모델과 순위를 만드는 모델이 같습니다.** 같은 모델을 상대로 점수를
올리면 모델을 잘 속이는 분자가 나오지 잘 듣는 분자가 나오지 않습니다. 그래서
실제로 분별력이 있는지 재봤습니다.

| | 측정값 |
|---|---|
| 생성 유도체(12개 모화합물) | 376종 |
| ΔpKi가 모델 오차범위(±0.7) 안 | **302종 (80%)** |
| ΔpKi가 LOO RMSE(1.4) 초과 | 12종 (3%) |
| 적용영역 밖 | 146종 (39%) |
| 기능 판정이 바뀜 | 대부분의 모화합물에서 **0종** |

**비칼루타마이드에서는 대조군(Cl·F·OH·메틸)이 약리단(CF3·나이트릴)보다 위에
올라옵니다.** ΔpKi 전 범위가 +0.04~+0.06입니다. 이 모델은 메틸과 나이트릴을
구분하지 못합니다 — 애초에 화학형 *사이*를 선별하려고 만든 fingerprint read-across
모델이지, 한 화학형 *안*에서 치환기를 최적화하라고 만든 것이 아닙니다.
10개 모화합물 중 약리단이 대조군을 이긴 것은 8개지만, 이긴 폭도 대개 오차범위
안입니다.

그래서 탭은 이렇게 동작합니다.

- |ΔpKi| ≤ 0.7인 행은 **「구분 불가」로 흐리게** 표시합니다.
- **대조군을 숨기지 않습니다.** 매 실행마다 "약리단 최고 Δ 대 대조군 최고 Δ"를
  계산해 적고, 대조군이 이기면 *"이 분자에서는 순위를 믿지 마세요"* 라고 씁니다.
  내장된 귀무가설입니다.
- 적용영역 밖 유도체는 **순위에서 빼서 따로** 둡니다. 더 나쁜 후보가 아니라
  채점되지 않은 후보라, 큰 숫자가 상위에 앉지 못하게 합니다.
- 결과 위에 *"이 탭은 최적화기가 아니라 가설 생성기"* 라고 고정으로 적습니다.

남는 쓸모는 분명합니다. **화학식까지 검증된 유효한 구조 목록**과, 그중 무엇이
적용영역 안에 있고 무엇이 모델의 분별 한계 아래인지입니다. 합성 우선순위를
정해주지는 못합니다. `test_design.js`가 11가지를 고정하며, 그중에는 대조군이
계속 생성되고 계속 대조군으로 표시되는지도 들어 있습니다 — 조용히 빼면 탭이
실제보다 훨씬 권위 있어 보이기 때문입니다.

## 길항제 순위 탭 — 사전 전체를 한 줄로 세우기

사전 206종을 모두 돌려 길항제로 판정된 **96종**을 우선순위대로 세우는 네 번째 탭입니다
(브라우저에서 약 0.1초). 열 제목을 누르면 다시 정렬되고, TSV로 복사됩니다.

정렬은 **구간 먼저, 같은 구간 안에서는 예측 pKi 높은 순**입니다. 하나의 점수로
합치지 않은 이유는, 합치는 순간 정작 봐야 할 불일치가 숨기 때문입니다. 증거의
종류(Tox21 판정, read-across 등급, 예측 pKi)는 애초에 같은 척도가 아닙니다.

| 구간 | 조건 | n |
|---|---|---|
| 우선 확인 | 실측·예측 등급 + pKi ≥ 5.0 + 구조와 모순 없음 | 31 |
| 참고 | 가능성 등급이거나, 결합이 약하거나(pKi 4–5), 증거가 엇갈림 | 16 |
| 낮음 | 포켓에 결합할 구조가 아니거나 pKi < 4.0 | 49 |

증거 등급은 별도 열입니다. 특히 **「문헌」 17종은 이 도구의 입력이지 발견이
아닙니다** — 기능 레퍼런스에 실린 물질이라 자기 자신과 유사도 1.00으로 맞습니다.
그걸 「예측」이라 적으면 순환 논리가 되므로 따로 표시하고, 체크박스 하나로
제외해 **도구가 스스로 찾은 79종**만 볼 수 있습니다.

### 강등 규칙 세 가지는 전부 첫 초안을 보고 만들었습니다

초안의 1위는 **DHEA**였습니다. Tox21은 길항이라 하지만 구조는 작용제(부피 큰
치환기 없는 3-케토 스테로이드)이고, DHEA는 안드로겐 전구체입니다. 길항제 모드는
기준 작용제와 함께 넣어 신호 감소를 재므로 **경쟁만 해도 잡힙니다** — 알려진
부분작용제 5종이 5종 모두 그렇게 나온다고 이미 문서에 적어 둔 바로 그 현상입니다.

고치는 과정에서 **한 번 더 틀렸습니다.** 레퍼런스 등재 물질을 「문헌」으로
표시하게 했더니, DHEA가 2위로 올라가 "문헌이 길항제라고 한다"로 읽히는 배지를
달았습니다. 실제 레퍼런스 라벨은 `agonist`입니다. 정반대였습니다.

그래서 최종 규칙은 셋입니다.

1. **레퍼런스 라벨이 반대면 강등.** 손으로 큐레이션한 약리가 작용제·부분작용제라고
   하는데 어세이만 길항을 가리키면, 여기서 가능한 가장 강한 불일치입니다.
   DHEA(agonist)와 MPA(partial)가 걸립니다.
2. **실측 길항 + 부피 큰 치환기 없는 스테로이드면 강등.** 그 치환기야말로
   스테로이드계 길항제를 안드로겐과 가르는 특징이고, 이미 기능 판정이 쓰는
   모티프입니다. 없으면 길항이 아니라 경쟁일 가능성이 큽니다 — 프레그네놀론,
   에스트론, 피나스테리드가 걸리고 사이프로테론·메게스트롤·클로르마디논은
   걸리지 않습니다.
3. **포켓 결합 근거가 약하면 최하 구간.** 포화지방산들이 유사도 0.28로 목록에
   들어와 있었는데, 포켓 판정이 「결합 가능성 낮음」이었습니다. 결합하지 않는
   것은 길항제일 수 없습니다.

**셋 다 지우지 않고 내린 뒤 이유를 화면에 적습니다.** 세포독성은 플래그만
답니다 — 세포를 죽여도 신호가 내려가니 과대평가될 수 있지만, 비칼루타마이드
자신이 세 어세이 중 하나에서 세포독성이라 강등에 쓰면 정작 교과서적 길항제가
묻힙니다.

고친 뒤 상위권은 디에노게스트·드로스피레논·메게스트롤·클라스코테론·
클로르마디논·사이프로테론·아팔루타미드·엔잘루타미드·다롤루타미드·
스피로놀락톤·비칼루타마이드·하이드록시플루타마이드·닐루타미드 순으로,
실제 항안드로겐 약리와 맞습니다. `test_rank.js`가 10가지를 고정합니다 —
순위가 1..N으로 빠짐없이 이어지는지, 알려진 항안드로겐이 상위 12위 안에
있는지, DHEA가 강등되고 이유가 붙는지, 상위 25종이 자기 단건 조회 결과와
일치하는지 등입니다.

### 접촉 표의 빨간 칸은 「충돌」이 아닙니다

이 칸은 "H12 충돌"로 표시돼 있었는데, 측정하지 않는 물리를 주장하는 이름이었습니다.
**입체 충돌(겹침·거리 위반)을 계산하는 단계는 이 도구에 없습니다.**

| 표기 | 조건 |
|---|---|
| 접촉 | 도킹 포즈에서 중원자 간 **4.5 Å 이내** |
| 접촉 (helix-12) | 위와 **같은 기준** + 그 잔기가 helix-12 소속(Thr877·Met895·Ile899) + 그 포즈가 **Ile899에도 닿음** |

두 상태의 차이는 세기가 아니라 **위치**입니다. 증거가 되는 건 "이 잔기와 부딪힌다"가
아니라 "이 포즈가 AF-2 표면 쪽으로 뻗어 helix-12 영역까지 간다"는 사실이고, 그것이
Ile899 신호입니다.

구체적인 증거는 DHT입니다. **DHT는 Thr877과 Met895를 비칼루타마이드와 똑같이
접촉합니다.** 다른 것은 Ile899 하나뿐이고, 그래서 DHT의 Thr877은 표시되지 않습니다.
Thr877 자체에 대해 새로 측정된 것은 아무것도 없다는 뜻입니다. Trp741과 Phe876은
내성 변이 잔기이면서도 helix-12 소속이 아니라 끝까지 파랑입니다. `test_predict.js`가
이 일곱 가지를 고정합니다.

### 「길항제」라고 쓰는 기준

판정은 네 등급이고 기준은 이게 전부입니다. 단정하지 못하면 **왜 못하는지 화면에
문장으로** 적습니다.

| 등급 | 표기 | 기준 |
|---|---|---|
| 실측 | 길항제 (실측) | Tox21에서 **길항제 모드 어세이**만 활성. 유효 어세이가 1개면 그렇게 밝힘 |
| 예측 | 길항제 (예측) | 최근접 유사도 **≥ 0.35**, 한쪽 근거 **≥ 50%** |
| 가능성 | 길항제 가능성 | 방향은 길항 쪽이나 유사도 0.20–0.35. 또는 유사도가 낮아도 구조 신호(부피 치환기·Ile899)가 있을 때 |
| 판단 불가 | 판단 불가 | 유사도 **< 0.15**이거나 증거가 갈림 — 이유 명시 |

0.15라는 바닥에는 근거가 있습니다. 라벨 38종을 유사도 구간별로 LOO 해보면:

| 최근접 유사도 | n | 정확도 |
|---|---|---|
| 0.50–1.00 | 23 | 87% |
| 0.35–0.50 | 11 | 64% |
| 0.15–0.35 | 4 | 100% |
| **< 0.15** | **0** | **—** |

마지막 줄이 핵심입니다. **표본이 아예 없습니다.** 라벨된 물질은 모두 서로
가까우니까요. 그 아래는 성능이 낮은 구간이 아니라 **한 번도 검증된 적 없는
구간**입니다. 게다가 레퍼런스 38종 중 17종이 길항제라서, 모든 것에서 먼 분자는
구조 유사성이 아니라 **레퍼런스 구성 편향** 때문에 길항제 만장일치를 받습니다.
피세틴이 정확히 그랬습니다 — 이웃 5종 전부 길항제, 유사도는 모두 0.09대. 그래서
"판단 불가"가 나왔고, 임계값만 내리면 그 편향이 자신 있는 오답으로 바뀝니다.

### 폴리페놀 공간에 실측 이웃을 넣었습니다

큐레이션된 38종은 약물과 농약이라 플라보노이드에 대해 한마디도 못 합니다. 그래서
**Tox21에서 한쪽 모드만 활성으로 확정된 물질 중 손으로 라벨하지 않은 16종**
(제니스테인·아피제닌·레스베라트롤·부틸파라벤·에스트론 등)을 read-across 이웃으로
씁니다. 라벨이 측정값이기 때문입니다.

넣어도 큐레이션 38종 LOO는 **32/38 그대로**입니다 — Tox21 판정과 똑같이,
정확도가 아니라 **적용 범위를 산 것**입니다. 효과는 이렇습니다:

| 물질 | 이전 | 이후 |
|---|---|---|

### 내성 변이체 Δ — 주장했다가, 다시 재고, 철회했습니다

**현재 상태: 철회.** 단건 화면의 변이체 패널은 제거했고, `describeShift`도 없앴습니다.
측정값은 저장소에 남겨 두되 해석을 거둬들였습니다. 어떻게 틀렸는지는 남겨 둘
가치가 있어 아래에 적습니다.

#### 주장

길항성을 결정하는 잔기(Trp741·Thr877·Phe876)는 **내성 변이**에서 나온 지식입니다.
접촉 횟수로는 안 됩니다 — Trp741은 작용제 75%/길항제 87%, Thr877은 22종 **전부**가
접촉합니다. 그래서 "곁사슬이 없어지면 어떻게 되는가"를 직접 재기로 하고, 같은
리간드를 2AM9(야생형)·2OZ7(T877A)·1Z95(W741L)에 각각 도킹해 차이를 봤습니다.
라벨 38종에서 길항제 −2.86, 작용제 +0.71, **분리폭 3.57 kcal/mol**이 나왔습니다.

#### 왜 틀렸나 ① — 이 README가 이미 반박하고 있었습니다

바로 아래 절에 **「어느 구조를 고르느냐가 리간드보다 순위를 더 많이 좌우한다」**
와 **「1Z95는 자기 공결정 리간드를 22종 중 1위로 올린다」** 가 적혀 있습니다.
1Z95의 공결정 리간드는 **R-비칼루타마이드**입니다. 그런데 비칼루타마이드의
ΔW741L = −3.5를 "길항제 구제"의 대표 증거로 썼습니다. 자기도킹 편향입니다.

서로 다른 세 결정의 절대 점수를 뺀 값은 애초에 돌연변이를 분리하지 못합니다.
해상도도, 곁사슬 로타머도, 공결정 리간드도 다릅니다.

#### 통제 실험

같은 2AM9 결정에서 **곁사슬만 in-silico로 잘라냈습니다.** 백본·박스·나머지
249개 잔기가 바이트 단위로 동일함을 검증했습니다. Thr→Ala는 절단이 정확히
일치하고, Trp741은 전체 절단(W741A)으로 "관문 제거"를 쟀습니다.

Trp741은 전체 절단(W741A, "관문 제거")과 실제 임상 변이 기하에 가까운
근사(W741L: 인돌의 CB·CG·CD1·CD2만 남기고 개명) **둘 다** 돌렸습니다.

| 클래스 | 옛 ΔT877A | 새 ΔT877A | 옛 ΔW741L | 새 ΔW741A | 새 ΔW741L |
|---|---|---|---|---|---|
| agonist (16) | +0.71 | **+0.03** | +3.18 | +0.52 | +0.46 |
| antagonist (17) | −2.42 | **−0.51** | −1.27 | −0.06 | +0.17 |
| partial (5) | −1.28 | −0.60 | +0.54 | +0.22 | +0.22 |
| **작용/길항 분리폭** | **+3.14** | **+0.55** | **+4.45** | **+0.52** | **+0.28** |

**가장 결정적인 한 줄.** AR에서 가장 유명한 내성 사실은 *"W741L이
비칼루타마이드를 작용제로 바꾼다"* 입니다. 그 대표 사례가 이렇게 됩니다.

| | 옛 (1Z95 교차결정) | 통제 (2AM9 곁사슬 절단) |
|---|---|---|
| 비칼루타마이드 ΔW741L | **−3.5** | **+0.4** |

**부호가 뒤집힙니다.** −3.5는 W741L의 효과가 아니라, 비칼루타마이드를
자기 공결정 구조(1Z95)에 되도킹한 값이었습니다.

| 물질 | 옛 → 새 (T877A) |
|---|---|
| Bicalutamide | −1.50 → **−0.10** |
| Spironolactone | −3.10 → **−0.50** |
| Testosterone | +2.40 → **+0.20** |
| Cyproterone acetate | −2.10 → −1.40 |

**분리폭의 83%가 사라졌습니다.** 0.5 kcal/mol은 도킹 점수 오차 안입니다.

#### 왜 틀렸나 ② — 남은 것마저 기능이 아니라 골격입니다

같은 ΔW741A를 **스테로이드 여부로** 갈라보면:

| 구분 | n | 평균 ΔW741A |
|---|---|---|
| 스테로이드 작용제 | 16 | +0.52 (W741L: +0.46) |
| **스테로이드 길항제** | 6 | **+0.83** (W741L: +0.93) |
| 비스테로이드 길항제 | 11 | **−0.55** (W741L: −0.25) |

| 분리 기준 | ΔT877A | ΔW741A | ΔW741L |
|---|---|---|---|
| 작용제 / 길항제 | 0.55 | 0.52 | 0.28 |
| **스테로이드 / 비스테로이드** | 0.21 | **1.09** | **0.77** |

Trp741 쪽에서는 **골격이 기능보다 2~3배 잘 설명합니다.** 실제 임상 변이에
가까운 W741L에서 기능 분리가 가장 약하다(0.28)는 점도 말이 안 됩니다 —
W741L이야말로 길항제를 작용제로 바꾸는 변이니까요.

**스테로이드 길항제가 스테로이드 작용제 쪽에 붙습니다.** Δ가 길항성을 잰다면
사이프로테론아세테이트와 스피로놀락톤이 음수여야 하는데 +0.5, +0.6입니다.
Trp741 곁사슬을 없애 포켓이 넓어지면 꽉 맞던 단단한 스테로이드는 접촉을
조금 잃고(+0.5 부근에 좁게 몰림), 모양이 제각각인 비스테로이드는 제각각
움직입니다. 재고 있던 것은 **모양**입니다.

`test_function.js`가 이 철회를 고정합니다 — 통제 분리폭이 작다는 것, 골격이
기능보다 잘 설명한다는 것, 스테로이드 길항제가 안드로겐 쪽에 붙는다는 것,
그리고 `describeShift`가 돌아오지 않았다는 것.

## 한계 — 솔직하게

**도킹 점수는 친화도 예측값이 아닙니다.** 문헌에서 흔히 r² 0.3–0.5로 인용되지만,
이 저장소의 22종 패널(2AM9, 실측 pKi 4.0–9.5)에서 실제로 측정해 보니 **r² = 0.03**
(배치 실패 1건 제외 시 0.15)로 사실상 상관이 없었습니다. 점수 차이 0.5 kcal/mol로
두 물질의 우열을 가르는 것은 물론이고, **순위 자체를 신뢰해서도 안 됩니다.**
도킹이 실제로 기여한 것은 순위가 아니라 범주형 판정이었습니다 — 들어가는가,
어느 잔기에 닿는가. 자세한 수치는 아래 「3단계 실행 결과」를 보세요.

- **2AM9는 작용제 결합 형태입니다.** 엔잘루타미드처럼 helix-12를 밀어내는
  길항제는 이 구조에 제대로 들어가지 않습니다. 실측으로 엔잘루타미드 +9.2,
  스피로노락톤 −1.2로 **배치 자체가 실패**했습니다(둘 다 실제로는 결합체).
- **그렇다고 변이체 구조가 대안인 것은 아닙니다.** AR은 ER처럼 helix-12가 밀려난
  고전적 길항 형태 LBD 구조가 마땅치 않고, 비스테로이드 리간드가 들어간
  구조들은 대부분 **점변이체**입니다(2OZ7 = T877A, 1Z95 = W741L).
  2OZ7은 T877A 변이체에 사이프로테론아세테이트가 결합한 구조이고,
  **Thr877이 Ala877이라 D-ring 앵커 하나가 아예 존재하지 않습니다.**
  스크립트가 이제 이를 경고로 알려줍니다. 변이 포켓에 대한 답이지
  야생형에 대한 답이 아니라는 점을 염두에 두세요.
- **수용체를 rigid로 고정합니다.** 곁사슬이 움직여야 들어가는 리간드는
  과소평가됩니다. smina의 `--flexdist` / `--flexdist_ligand` 옵션으로 포켓 주변
  곁사슬을 유연하게 두고 재실행해 보세요.
- **구조수를 제거합니다.** Arg752 매개 수분자가 중요한 리간드는 영향을 받습니다.
- **대사 활성화를 모릅니다.** flutamide는 전구체이고 활성은 hydroxyflutamide에
  있는데 2D 구조가 거의 같아, 1단계에서 flutamide가 2 log 이상 과대평가됩니다.
- **4-aza 스테로이드를 오분류합니다.** finasteride는 5α-환원효소 억제제이지
  AR 리간드가 아니지만 2D 유사도로는 DHT와 구분되지 않습니다. 이 항목은
  3단계 도킹이 실제로 걸러냅니다(배치 실패).
- **에스트라디올은 3단계로도 안 고쳐집니다.** 1단계가 +2.5 log 과대평가하는데
  도킹에서도 22종 중 가장 좋은 점수(−11.3)를 받습니다. 실측은 5.50입니다.
  스테로이드 코어가 포켓에 잘 맞는 것은 사실이고, AR에서 약한 이유는 A-ring
  방향족화에 따른 전자적 차이라 형태 기반 평가로는 잡히지 않습니다.
- **입체화학을 무시합니다.** 1단계 파서는 키랄리티·동위원소 표기를 읽기만 하고
  값은 쓰지 않으므로 거울상 이성질체가 같게 평가됩니다. 반면 방향족성은
  인식하므로 케쿨레 표기(PubChem의 Canonical SMILES 형식)와 소문자 표기는
  같은 결과를 냅니다.
- **금속 함유·고분자·혼합물은 범위 밖입니다.** 징크피리치온 같은 금속 배위
  화합물은 기술자 자체를 신뢰할 수 없습니다.

**모든 결과는 세포실험 전 우선순위 선별용입니다. 규제 제출이나 안전성 판정의
근거로는 사용할 수 없습니다.**
